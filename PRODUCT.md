# Petra

## Platform

Web, Arabic (Iraq), RTL. Responsive from 320 to 1440 pixels and beyond. Display time is Asia/Baghdad; stored time is UTC.

## Product and people

Petra connects animal owners with private animal records, veterinary appointments, clinic stores, transport and a social community. There are exactly five personas: customer, doctor, clinic member, driver and platform administrator. A clinic is the scope for its commerce, inventory and accounting. Professional workspaces require server authorization and verification.

## Stack

Existing Next.js App Router and React web application, NestJS API, PostgreSQL and Redis. Keep the current architecture and working workflows. This redesign changes presentation and navigation, not resource permissions or financial rules.
