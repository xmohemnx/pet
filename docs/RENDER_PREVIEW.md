# معاينة واجهة Petra على Render

اختار المالك بتاريخ 2026-10-23 معاينة مجانية للواجهة داخل مساحة `My Workspace`. النطاق خدمة ويب واحدة بخطة `free`، من فرع `codex/deployment-preparation-20261022` في `xmohemnx/pet`. لا API أو عامل أو Redis أو اتصال Supabase في هذه المعاينة. قاعدة Supabase السابقة باقية ومنفصلة.

## إعداد الخدمة

- Docker من Git، سياق المستودع `.` وملف `infra/render/preview.Dockerfile`.
- المنطقة `frankfurt`؛ الخطة الصريحة `free` المقبولة في أداة Render.
- `NODE_ENV=production`، `APP_ENV=production`، `PETRA_WEB_PREVIEW=true`، `PETRA_DEMO_MODE=false`، `PORT=10000`، `HOSTNAME=0.0.0.0`، و`APP_ORIGIN` للرابط الفعلي للخدمة.
- النشر التلقائي معطل للمحافظة على نسخة معاينة محددة؛ تحديث الوثائق وحده لا يستدعي بناء آخر.
- لا تضع `API_BASE_URL` أو بيانات اتصال قواعد أو أسرار جلسات وبريد وتخزين. مشغل المعاينة يرفض البدء عند وجود الإعدادات الخلفية الحساسة المفحوصة أو إيقاف علم المعاينة.

لا تغيّر هذه الخدمة إلى تشغيل كامل بمجرد إطفاء العلم. التشغيل الكامل يحتاج صور API والعامل وRedis والبريد والتخزين والفاحص، واختبار اتصال PostgreSQL والتحقق من هوية TLS، وتقييم التكلفة مستقلاً. راجع ADR030 ودليلَي النشر وSupabase.

## السلوك والتحقق

المتاح الصفحة الرئيسية وتصميم الدخول والتسجيل والاستعادة. توجد لافتة واضحة، والنماذج معطلة. API يعيد 503، وdemo وروابط الأمان مخفية، وبقية الوجهات تشرح حدود المعاينة. robots وHTTP يمنعان الفهرسة. لا تعرض بيانات تجريبية غير موسومة ولا توحي بتنفيذ عملية محفوظة.

```bash
pnpm --filter @petra/web build
pnpm test:preview
pnpm check
pnpm security:built
```

فحص المعاينة يشغّل Next standalone الفعلي، ويثبت عدم إرسال أي طلب إلى خادم خلفي مراقب، ورفض أساليب API وكتابة الصفحات والمسارات الخاصة، وتعطيل النماذج، وأحجام 320/390/1440 مع axe. يفحص أيضاً مشغل الصورة ومعالجة الإنهاء. لا يتطلب حسابات أو قواعد اختبار أو أسراراً.

الصورة تشغّل Next بمستخدم غير root. يتحقق مشغلها من الصفحة والدخول ورفض API عبر loopback ويطبع نتيجة مختصرة دون بيانات صفحات أو أسرار. عند النشر راقب deploy الفعلي حتى `live` ثم تحقق من ظهور رسالة `Petra preview verified` في سجل النسخة نفسها. لا تعادل الرسالة اختبار شهادة HTTPS من خارج Render أو اختبار متصفح بعيد.

تعذر جلب مرجع الأسعار الحالي بصيغتي Markdown وHTML بسبب 403 من سياسة شبكة بيئة العمل. لا توجد وعود بحدود مجانية ثابتة أو استمرار توفر الخدمة. عند قبول Render للخطة المجانية لن ننشئ بديلاً مدفوعاً تلقائياً إذا رُفضت أو تطلب الحساب ترقية.
