## رحلات محفوظة ومختبرة

1. حساب موثق → حيوان خاص ووصاية → وقت طبيب معتمد في فرع عيادة → حجز ذري → موافقة → SOAP → توقيع وإضافة/نتيجة لاحقة → متابعة وملف خاص ومحادثة. نقل الملكية يحتاج قبول الحساب المستلم ويلغي تفويضات القديم.
2. عيادة معتمدة → منتج SKU ومورد → PO→GRN→bill وطبقة FIFO → سلة متعددة العيادات → حجز → تحصيل sandbox → تجهيز→شحن→تسليم → إيراد/عمولة/COGS → مرتجع جزئي وقيد دائن واستعادة مشروطة → تسوية اختبارية ومطابقة.
3. خدمة → باقة → اشتراك prepaid → زيارة موقعة مطابقة → entitlement واحد واعتراف تدريجي بالإيراد. الإقامة وحدة/تواريخ بمنع تداخل وحضور وإتمام؛ الإلغاء قبل الخدمة يعكس القيد مرة واحدة.
4. ملف اجتماعي يختار خصوصيته → منشور/صورة أو فيديو quarantined→تحويل جاهز→نشر → تفاعل/تعليق → بلاغ/إزالة. المتابعة الخاصة تحتاج قبولًا، والحظر يمنع الرسائل والوسيط والمنشور مباشرة.
5. إعلان تبنٍّ بمراجعة → طلب ببيانات خاصة → قبول → إقرار المستلم→تسليم ونقل ملكية. بلاغ إنقاذ يخفي العنوان→مراجعة→عيادة تقبله فعليًا→معالجة وحل.
6. طلب نقل اختباري → سائق معتمد بمركبة متاحة يقبل ذريًا → حالات انتقال → موقع للمشاركين 60 ثانية → اكتمال ومحو الموقع → مستحق بالدفتر. بلاغ سلامة خاص يحفظ منفصلًا.
7. حدث مجال committed→outbox→Redis→مستهلك idempotent→إشعار داخل التطبيق. فشل محدود retries→dead letter→إعادة محاولة إدارية؛ لا يلغي نجاح معاملة الأصل.

## البيانات وحدود الملكية

الهوية والجلسات منفصلة عن العضويات؛ الحيوانات والموافقات تملكها علاقة المالك؛ المنتجات والمورد والمخزون والفروع والأوامر نطاق عيادة. checkout parent يتفرع clinic_orders وorder_lines، وتُخزن أسعار وتكاليف snapshots على الخادم.

الدفاتر منفصلة: ledger_entities/accounts/journals/lines/periods، والموافقة والصرف والكشف والمطابقة لها مستندات وسجل تدقيق. الأرصدة مصدرها قيود posted، والطبقات تحفظ FIFO، وأموال التبرع المقيدة ليست دخلًا. القيد الموقع/المرحل لا يعدل، والتصحيح مستقل.

وسيط طبي خاص بالحيوان، واجتماعي خاص بالمالك ثم بمنشور مصرح. الملفات ليست public static. أوقات القصة والتفويض والموقع وحجز المخزون تُفحص على الخادم. لا فيديو منشور قبل التحويل.

هذه رحلات محلية وليست جميع توسعات الخطة. حالة كل مرحلة وحدود الدفع والإطلاق وExpo في REQUIREMENTS_TRACEABILITY وKNOWN_ISSUES.
