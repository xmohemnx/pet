## التحقق وإعادة الإنتاج

الدورة النهائية: **31passed،1skipped(3.3m)**؛30سيناريو وظيفياً ومرحلة تصوير، مع تخطي تصوير دفعة أنواع الحسابات القديمة عمداً. نجحت48وحدة وفحوص المصدر والبناء. هذا اختبار للمسارات المختارة، لا إعادة لجميع اختبارات المنصة أو شهادة جاهزية إنتاجية. تاريخ الإخفاقات المصححة وحدود اللمس المحاكى والمتصفحات في [التقرير](../../../audits/UI_UX_RELEASE.md).

بعد تجهيز الخدمات المحلية والبناء، ومن مصدر مثبت دون تعديلات على ملفات التشغيل والاختبارات:

```bash
PETRA_CAPTURE_UIUX_PROOF=true PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium pnpm test:e2e ui-ux.spec.ts auth-ux.spec.ts account-types.spec.ts redesign.spec.ts social-rebuild.spec.ts --workers=1
```

مشغّل الاختبار ينشئ قاعدة `petra_e2e_<pid>` محلية ويحذفها بعد الانتهاء. لا تستخدمfixtures علىSupabase أو بيانات حقيقية. لا نشر عام أو تفعيل دفع حقيقي ضمن هذه الدفعة.
