# صور Petra الفعلية — المراجعة الأولى التاريخية

هذه صور Chromium أصلية من موقع يعمل محلياً ببيانات اختبار اصطناعية في قاعدة معزولة، وليست مخططات تصميم أو بيانات مرضى وعملاء حقيقيين. تسبق اختصار مراجعات المدير وفصل الشارات وترتيب المتجر؛ راجع [النسخة النهائية](../3baffbdb/README.md).

المصدر: [`8a6c984d`](https://github.com/xmohemnx/pet/commit/8a6c984d5674885e7d7ba289770d376c55c70eef)؛ شجرة المصدر `a06f0609711c2013454d9a881c894867b59d57bc`. [بيان الالتقاط](manifest.json) و[الأبعاد والبصمات](artifacts.json). اختُبرت أيضاً عروض 320 و768 بكسل دون تجاوز أفقي؛ الصور المحفوظة بعرضي1440 و390 بكسل. البنر يستخدم صورة هوية مفهومية موجودة في المشروع، وليس حالة طبية أو إعلاناً فعلياً لعميل. التواريخ والأسماء والنتائج اختبارية؛ ليست إثباتاً لنشر عام أو نتائج علاج حقيقية.
