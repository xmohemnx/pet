## إعادة الإنتاج

`pnpm build` ثم `pnpm test:social-proof` من commit مثبت وحالة نظيفة لملفات التشغيل والاختبارات. يشغّل الأمر PostgreSQL محلياً بقاعدة مؤقتة، وينشئ حسابات ومحتوى فعلياً، ثم يحذف القاعدة. لا تشغّل fixture على Supabase. راجع [أدلة التنفيذ](../../../audits/RELEASE_EVIDENCE.md) للمتطلبات والاختبارات.

المقاييس تجربة محلية دافئة وحيدة لكل صفحة؛ ليست قياسات حقلية أو شبكة 3G أو percentiles. سجلت القصة أطول حدث تفاعل 32ms؛ البقية بلا عينة مؤهلة، فلا تعني INP=0. الملف [manifest.json](manifest.json) يحفظ وقت كل صورة والمتصفح والمسار وقياساته. لا حُذفت عناصر ولا جُمّلت الصور بعد الالتقاط.
