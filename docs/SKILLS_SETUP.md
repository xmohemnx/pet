# تجهيز مهارات Petra

توجد 21 مهارة محلية في `.agents/skills` وفق `INSTALLATION.json`، تضم 441 ملفًا. هي أدلة وأدوات يستخدمها المساعد أثناء التطوير. يقرأ المساعد ملف `SKILL.md` المناسب عند الحاجة؛ لا يشغل الموقع جميع المهارات كخدمات، ولا ينشرها تثبيت المشروع إلى حسابات خارجية.

## تجهيز الأدوات

من جذر المشروع، في Linux أو macOS أو WSL، مع Node 24.5+ ضمن السلسلة 24 وnpm و`sh` و`bash` و`curl` أو `wget`، وChrome/Chromium لفحص المتصفح:

```bash
pnpm skills:setup
pnpm skills:check
```

الإعداد يصلح صلاحية تنفيذ مشغل Impeccable، ويتحقق من محرك النسخة المثبتة في ملفه `VERSION`، ويثبت Vercel CLI بإصدار محدد. التنزيل الأول يحتاج اتصال GitHub وnpm مسموحًا والتحقق من TLS؛ لا تعطل الشهادات أو تتجاوز سياسة الشبكة.

- **Impeccable:** النسخة `0.1.16`؛ المشغل الأصلي يتحقق من SHA-256 الملف المنشور قبل تشغيل محركه. الملفات التنفيذية في `.data/skill-runtime/impeccable`، خارج Git وحزمة المصدر.
- **Vercel CLI:** النسخة `65.2.0`؛ الاعتماديات في `.data/skill-runtime/vercel`. يستخدم المشغل مدخل CLI الرسمي `dist/vc.js` مع وكيل Node المهيأ، دون إضافة اعتمادات إلى تطبيق الموقع.
- **GSAP وLenis:** مكتبات موجودة ضمن اعتمادات `apps/web` المثبتة من lockfile. `lenis-integration` دليل Petra المحلي، وليس مهارة رسمية مستقلة من مستودع Lenis.
- **Taste:** أدواته تعمل عبر Node ومراجعها محلية. فاحص المتصفح يحتاج Chrome/Chromium مثبتًا؛ البحث عن صور خارجية يحتاج شبكة إلى مزوده وقت الاستخدام. مشغل `skills:run` يحدد متصفح الأدوات، ويعالج تشغيل Chromium كمستخدم root داخل الحاوية بإضافة العلم المطلوب للعملية؛ يبقى عزل المتصفح مفعلاً للمستخدم العادي. لا يعدل إعدادات المتصفح العامة أو سياسة الشبكة.

أمثلة فحص وتشغيل، دون نشر:

```bash
pnpm skills:impeccable engine-probe
pnpm skills:vercel --version
node .agents/skills/taste-skill/scripts/draw.mjs --list sectors
```

السكربتات التي تستدعي `vercel` أو `impeccable` بالاسم يمكن تشغيلها عبر `pnpm skills:run` ليُضبط PATH الخاص بالأدوات لهذه العملية فقط، دون اعتماد على تثبيت عالمي. مثال فحص:

```bash
pnpm skills:run vercel --version
pnpm skills:run impeccable engine-probe
```

الفحص يتحقق من قائمة المهارات ورؤوس ملفاتها وروابطها المحلية وعدم وجود symlinks وصياغة السكربتات وإمكانية تشغيل الأدوات بالإصدارات المحددة. لا ينفذ نشرًا أو تحليل حساب مدفوع أو تغييرًا في الموقع.

## حساب Vercel

أكد المالك أنه لا يملك حساب Vercel. أداة CLI مثبتة، ولا يوجد ربط حساب أو مشروع أو نشر عليها. ربط الحساب شرط عند استخدام مهارات النشر أو تحليل مشروع Vercel؛ لا يلزم لتجهيز بقية المهارات. لا تنشئ حسابًا أو خدمة مدفوعة تلقائيًا.

إذا اختار المالك استخدام Vercel لاحقًا، يُكمل تسجيل الدخول من طرفيته الخاصة:

```bash
pnpm skills:vercel login
pnpm skills:vercel whoami
pnpm skills:check --with-auth
```

في بيئة مقيدة الشبكة يجب أن تسمح إعداداتها المدعومة بنطاقات المصادقة وAPI التي يحتاجها Vercel. لا يوفر تثبيت CLI صلاحيات الشبكة أو الحساب تلقائيًا. لا ترسل مفاتيح في المحادثة ولا تطبع `VERCEL_TOKEN` أو تبحث عن أسرار في ملفات البيئة، حتى إذا تضمن دليل قديم مثالًا يطبعها. استعمل دخول CLI أو مدير أسرار خاصًا موثوقًا. لا تستخدم fallback نشر مجهول كبديل لمصادقة الحساب.

## حفظ المهارات

ملفات المهارات واللقطات الـ522 التي طلب المالك استعادتها باقية. تغيرت صلاحية تنفيذ مشغل Impeccable فقط، دون تعديل محتواه أو إعادة حذف المهارات. cache الأدوات و`.vercel` وملفات البيئة خارج Git. أوامر الإعداد قابلة لإعادة التشغيل بعد تنزيل المستودع، ولا تتطلب رفع أدوات التشغيل الكبيرة إلى GitHub.

لا تعني سلامة الملفات أن كل عمليات الخدمات الخارجية اختُبرت. الأدلة المحلية الحالية في `docs/evidence/skills-runtime-2026-10-23.json`.
