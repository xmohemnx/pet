## الحالة

## ما أُنشئ

- monorepo جديد من مستودع فارغ؛ Next.js 16.4.2 + React 19.3.1، NestJS 12.2.0، TypeScript 5.9.3، pnpm 11.25.0 على Node 24.
- الصفحة العامة العربية وواجهة عميل تفاعلية ومعاينة مالية العيادة، وثلاث مساحات تعريفية للطبيب والسائق والإدارة. خمس مساحات فقط، والتجارة ضمن العيادة.
- هوية teal/orange، tokens وخطوط محلية ورسم SVG أصلي، RTL وresponsive وreduced motion.
- API health/readiness وOpenAPI وبيانات التصميم عبر GET مع مخططات Zod. العرض محصور في `/demo` ومغلق دون flag صريح في الويب والخادم.
- PostgreSQL وRedis محليًا؛ migration جديدة للجداول التأسيسية وseed حتمية بلا تسجيل دخول أو منح أذونات.
- عقد حدث مالي مبكر بوحدات صحيحة وIQD ثلاث منازل وعرض BigInt؛ لا posting أو payment processor.
- CI محفوظة وفحوص lint/types/unit/E2E/axe وأسرار واعتماديات، ووثائق ADR والخريطة والقاموس والتتبع.

## إصلاحات نتجت عن الفحص

- استُخدمت مسارات cache داخل `/workspace` لتجنب منزل مستخدم غير قابل للكتابة.
- تحديث أدوات الاختبار وفحص الأسرار أزال تنبيهات الاعتماديات المعروفة؛ لم يُعطّل التحقق من TLS أو التواقيع أو checksums.
- استُثنيت حرفيًا سلسلة اتصال Compose المحلية المعروفة من secretlint؛ لا استثناء عام لسلاسل الاتصال أو مفاتيح حقيقية.
- احتواء تمرير جدول RTL تم بإضافة positioning للحاوية؛ لم يُخفَ تجاوز الصفحة بتعطيل overflow على body.
- استُبدل المسار الديناميكي بمسارات صريحة للشخصيات الخمس لضمان 404 للمسارات غير الموجودة قبل streaming.
- أخذ الصور وفحص التباين بعد اكتمال الخطوط وحركة الدخول؛ إصلاح انتظار اختبار viewport لعنوان الصفحة المطلوبة بدل عنوان loading المؤقت.
- تشغيل Next dev عبر helper يحمّل `.env` دون تمرير flag غير مدعوم إلى child NODE_OPTIONS. السماح بـ127.0.0.1 فقط كـorigin تطوير إضافي وفق توثيق Next المثبت.
- تعطيل توليد Next التلقائي لـAGENTS الفرعي حفاظًا على تعليمات المشروع؛ لا ملف تعليمات مولد متبقٍ.
