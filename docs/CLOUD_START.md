# Petra — بدء النسخة التشغيلية المحلية 0.14.0

استعمل `/workspace/pet` واقرأ AGENTS وPROGRESS وKNOWN_ISSUES وREADME وOPERATIONS_RUNBOOK. أذن المالك باستكمال المراحل دون توقف لمراجعة بينية؛ لا تنشئ worktree أو حسابات ذات امتيازات تلقائية. الموجود شرائح ويب محفوظة ومختبرة، وليس كل تفاصيل master plan أو إطلاق إنتاج.

## المتطلبات والإعداد

Node 24 وpnpm 11.25.0 وDocker Compose وFFmpeg وFFprobe. في كل طرفية:

```bash
cd /workspace/pet
export XDG_DATA_HOME=/workspace/.cache/data
export XDG_CACHE_HOME=/workspace/.cache/cache
export XDG_STATE_HOME=/workspace/.cache/state
export npm_config_cache=/workspace/.cache/npm
export NEXT_TELEMETRY_DISABLED=1
```

عند أول تشغيل أو تغير lockfile نفذ `bash scripts/install-cloud.sh`: frozen install، إعداد السر محليًا مع حفظ الموجود و0600 دون طباعة، Compose للخدمات، migrations وseed، فحوص وبناء. لا تعدل checksums لترحيل مطبق. مخطط الرعاية يحتاج btree_gist؛ قاعدة محلية ومستخدم الترحيل يسمحان بتثبيته. لا تفترض استمرار Docker أو بيانات volumes بعد استعادة snapshot.

لا حسابات دخول أو إدارة/مالية من seed. APP_ENV=local، APP_ORIGIN يطابق origin الويب تمامًا، وAPI_BASE_URL الداخلي الافتراضي 4000. لا تضع --env-file في NODE_OPTIONS؛ مشغل الويب يحمل .env. لا تطبع السر أو كلمات مرور أو روابط تحقق/استعادة أو TOTP أو dumps.

## العمليات المستمرة

افحص المنافذ وأعد استخدام خدمة متوافقة بدل قتل عملية مجهولة. بعد الإعداد:

- طرفية أولى: `pnpm dev:api` على 4000. يعاد البناء عند البدء؛ أعد تشغيله بعد تعديل API.
- طرفية ثانية: `pnpm dev:web` على 3000.
- طرفية ثالثة: `pnpm dev:worker` بعد بناء API. فحصه 4002 على loopback.

GET API health يعيد phase=inventory-discovery-transport-local، وready يفحص PostgreSQL/Redis. GET pets دون جلسة=401، وcare دون جلسة يعود إلى login. عامل المهام يتصل Redis ويعالج outbox والإشعارات والفيديو وحجوزات المخزون المنتهية. Redis queue منفصل بحسب اسم قاعدة البيانات. فشله لا يلغي معاملة محفوظة؛ راجع `/admin/operations` للأحداث الفاشلة وإعادة المحاولة.

PostgreSQL 5432، Redis 6379، Mailpit SMTP 1025 وUI/API 8025، كلها loopback. Mailpit اختبار محلي لا تسليم بريد خارجي. لا تعرضه للإنترنت ولا تقدم روابط معاينة loopback للمستخدم؛ اذكر نتيجة التشغيل وأرفق الصور عند الحاجة.

## البيانات والأدوار

ينشئ المطور حسابه عبر register ويؤكد البريد من Mailpit. اعتماد مهني يدوي من مراجع بجلسة TOTP؛ المنح المحلي بأداة operator صريحة وفق README، ولا تنفذه عند startup. التفويض المالي منفصل ومعد ومعتمد من حسابين؛ scripts/grant-local-finance.mjs يحتاج flag صريحًا وMFA ومنحة إدارة، ويرفض الإنتاج.

الخدمات والمنتجات تدار داخل العيادة. الطبيب يحتاج انتسابًا وموعدًا وموافقة مالك سارية للملف الطبي. المالية الحالية sandbox فقط وتُرفض خارج local؛ لا PSP أو تحويل أو تبرعات حقيقية. الصور والفيديو في `.data/media` خاصة، والفيديو لا ينشر قبل معالجة FFmpeg. لا تستعمل ملفات أشخاص حقيقيين قبل سياسة تخزين وفحص واحتفاظ معتمدة.

## الفحوص والاسترجاع

```bash
pnpm check
pnpm test:db
pnpm build
pnpm security:built
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium pnpm test:e2e
pnpm backup:verify
pnpm audit --audit-level high
```

E2E ينشئ قاعدة petra_e2e وسرًا ومجلد وسائط مؤقتًا، وخوادم 3100/3200 و4100/4101 وعاملًا 4102، ثم يحذف اختباره فقط. يحتاج Docker وMailpit وRedis وFFmpeg. fixtures تستخدم مكتبة الهوية الرسمية وMFA داخل القاعدة المؤقتة فقط؛ لا تضعف rate limits. على جهاز آخر ثبّت Chromium الرسمي إن غاب النظامي.

backup:verify يصدر snapshot متسقة ويسترجعها إلى قاعدة منفصلة ويقارن محتوى الجداول والوسائط ووجود triggers، ثم يحذف قاعدة التحقق. dumps في `.data/backups` بيانات حساسة لا ترفع إلى Git؛ الافتراضي حذف الأرشيف بعد التحقق. لا تنقل بيانات إنتاج إلى fixtures.

المستودع mount_path=pet. `/workspace/.git` الفارغة placeholder لا checkout أخرى. Git كان unborn دون commit؛ لا تدّعِ استرجاع الشفرة من remote أو snapshot بمهمة جديدة قبل إثباته. حفظ المسودة لا ينشر البيئة؛ التفعيل يحتاج مراجعة وحفظ ونشر من الإعدادات.

## حدود الأمان الجديدة

اقرأ SECURITY_REVIEW قبل تغيير حدود الرفع أو Origin أو CSP أو MFA. API افتراضيًا loopback. بعد ترحيل 0014 تحتاج الإدارة والاعتماد المالي دخولًا جديدًا؛ الاعتماد المالي يحتاج جلسة دون 30 دقيقة. إعداد install يفعل Git hook ويشغل security:built بعد البناء. لا تعرض root المستودع كـstatic ولا تضع الوسائط تحت public/.next ولا تقدم env أو traces ضمن artifacts.

## الكتالوج والمتجر

0.12.0: طبّق 0020/0021، وأعد API والعامل. لا تعدل migrations مطبقة. لكل عيادة storefront أولي ينشأ تلقائياً، ويظهر للمتسوق فقط إذا نشرت الواجهة واعتمدت العيادة. إدارة الصور والخصائص داخل clinic/:id/commerce، والسياسات والشعار/الغلاف داخل clinic/:id/storefront؛ التفاصيل تحت marketplace/products/:id وmarketplace/stores/:id. لا تنقل الصور إلى public، ولا تسمح بربط ملف طبي أو صورة موظف آخر غير منشورة بالمورد نفسه.

كل خيار منتج SKU مستقل؛ السعر والمخزون النهائي من الخادم. الصور تتطلب موافقة نشر، وإزالتها أو إخفاء المنتج/المتجر يلغي إذن الارتباط. قد يبقى الملف متاحاً لارتباط منشور آخر مشروع أو لصاحبه. راجع ADR 006 وcatalog.spec؛ لا مزود إنتاج أو شحن وضرائب تلقائية من سياسات النص.

## العمليات الجديدة في 0.13.0

طبّق migrations حتى 0027 دون تعديل checksum سابق. أعد API والعامل والويب من البناء الجديد؛ health phase=inventory-discovery-transport-local. المخزون تحت clinic/:id/inventory والتقارير المؤرخة clinic/:id/finance/statements. لكل عيادة مستودع رئيسي، وطبقة FIFO تتبع مستودعاً ودفعة وصلاحية وحجراً؛ AVAILABLE يستبعد المنتهي والمحجور والمحجوز. استلام جزئي يرحل الكمية الفعلية، وفاتورة PO بعد استلامه كاملاً، وإتلاف باعتماد شخص آخر وMFA حديث. لا تغير on_hand أو paid_minor من المتصفح.

عناوين المشتري خاصة، والطلب يحفظ snapshot لا تتغير بحذفها. التتبع يدوي من الفريق المخول، وليس تكاملاً مع مزود شحن. القصص المميزة تمدد عرض القصة بموافقة حتى سنة وتظل وفق خصوصيتها وحظرها، وإزالتها تسحب إذن المصدر المنتهي. البحث والمشاركة لا يتجاوزان visibleSql. المحادثة تحدث كل أربع ثوان عند ظهور الصفحة؛ لا WSS أو صوت/CDN ضمن ذلك.

النقل المجدول حتى 30 يوماً، وخمسة حيوانات بمركبة ملائمة للعدد والأنواع والراكب؛ يعاد فحص حق booking لكل حيوان عند الإسناد. العامل يلغي الموعد غير المقبول بعد ساعتين، ولا خصم أو غرامة جديدة. التسعير محلي بالمسافة المباشرة، ومزود الطرق والدفع والتأمين ليس مفترضاً. راجع ADR 007–010 وKNOWN_ISSUES قبل أي توسيع إنتاجي.

## تشغيل 0.14.0

طبق migrations 0028–0030 دون تعديل السابق، ثم أعد API والعامل والويب. الكوبون يحسب الحجز غير المنتهي والتحصيل استخداماً؛ الإلغاء/الانتهاء يحرره، والمرتجع لا يعيده. إذا تبدلت معاينة السعر، أعد المعاينة؛ لا تعدل لقطات الطلب أو قيوداً منشورة لتجاوز الرفض. إعداد الضريبة تجريبي صفر افتراضياً، بجلسة MFA مالية، ولا يفعل أي ضريبة قانونية أو مزود دفع خارجي.

التجميل: أنشئ خدمة في الفرع وغرفة وعضواً بصلاحية service_staff أو clinic_admin، ثم وقتاً يستوعب المدة والإضافات. سجل الإشغال المشترك يمنع التعارض مع الزيارة الطبية أيضاً. الإخفاء لا يلغي حجزاً سابقاً؛ ألغِه برد اختباري قبل التنفيذ أو راجع التسوية إذا نفد المستحق. تأكيد الإتمام عمل موظف مخول وينقل المؤجل إلى إيراد مرة واحدة. صور الإتمام بموافقة مستقلة؛ يمنع نشر الملف المرتبط في المجتمع/المتجر.

المكتبة: مسودة المدير ثم مراجعة طبيب مختلف عن محرر النسخة ثم نشر صريح. كل تعديل يعيد المسودة ويخفي المنشور. تعليق العيادة أو الطبيب/انتسابه أو مرور سنة على المراجعة يحجب القراءة، ولا يمثل إكمال review اعتماداً خارجياً. طلب التصحيح والرد يحفظان النسخة القديمة؛ إصلاح المحتوى يحتاج نسخة ومراجعة ونشر جديدين. لا تنشر محتوى علاجياً اصطناعياً للمستخدمين الحقيقيين. لا تضف بيانات/كلمات مرور افتراضية للبيئة.
