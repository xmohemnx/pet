# مسار تجهيز Petra للنشر — 0.19.0

العراق وIQD والاسم Petra مؤكدة من المالك. البداية بأدوات مجانية قابلة للتطوير؛ لا نطاق أو استضافة أو حسابات مزودين مقدمة. اسم الموقع لا يثبت تسجيل كيان أو اعتماد تراخيص أو ضرائب.

| النطاق        | المنفذ محلياً                                                                        | المتبقي للإطلاق                                                        |
| ------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| الواجهات      | هوية جديدة وصفحة عامة ودخول وإطار موحد للشخصيات الخمس مع RTL                         | اعتماد المالك البصري وبيانات الجهات الفعلية                            |
| المجتمع       | WS وحضور اختياري وكتابة وصوت ومرفقات وHLS خاص                                        | تحميل واسع، رفع قابل للاستئناف، بث حي إن لزم، سياسة احتفاظ             |
| الوسائط       | موصل S3 مشفر وClamAV فعلي وحجر وإعادة محاولة وتنظيف مصدر خام                         | خوادم دائمة وتحديث تعريفات ومفاتيح مدارة وتدوير واسترجاع واعتماد إنتاج |
| التجارة       | تصنيفات هرمية ووسوم وفلاتر، إضافة لدورات المخزون والمحاسبة القائمة                   | مزود دفع وشحن واعتماد ضريبي وفوترة قانونية                             |
| التكسي        | موصل OSRM وطلب خارجي ناجح عبر الوكيل، وخريطة اختيارية وإسناد بموافقة ونزاعات sandbox | مزود طرق باتفاق تشغيل وسياسات تعويض وتأمين وتشغيل محلية معتمدة         |
| الطبيب        | ملفات خاصة ومواعيد وموافقات وتوثيق داخلي                                             | تحقق ترخيص خارجي، دفع الحجز، مستندات وتوقيع رسمي                       |
| التشغيل       | صور تشغيل وتعريف TLS وفحص جاهزية مغلق عند النقص، وبناء وفحص صور محلي موثق            | نشر على خادم المالك واختبار TLS وأدوار محدودة ومراقبة ونسخ خارج الخادم |
| حقوق البيانات | ثوابت خصوصية وحظر ووصول وتنظيف تقني لبعض الملفات                                     | دورة طلبات حقوق واحتفاظ وحجز قانوني ومراجعة معتمدة                     |
| الأمن         | فحوص مصدر وأصول وجلسات وملفات وتزامن ونسخ/استرجاع محلية                              | مراجعة أمنية مستقلة مربوطة بالنسخة، لا ضمان انعدام ثغرات               |

`production:check` يجمع حقائق التنفيذ وإعدادات الخدمة والأدلة المستقلة، ولا يسمح لمتغيرات البيئة بادعاء تنفيذ مزود أو سياسة غير موجودة. نجاح `/ready` لا يساوي تصريح نشر. الأسرار تدخل في ملف خاص أو مدير أسرار، ولا تُرسل في المحادثة أو إلى المتصفح. الدفع ورفع الملفات الإنتاجي لا يفتحان تلقائياً بسبب إعادة التصميم.
