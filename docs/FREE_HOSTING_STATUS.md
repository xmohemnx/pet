# حالة تشغيل Petra المجاني — 2026-10-23

طلب المالك تشغيل الوظائف للتصفح والاختبار عبر الإنترنت بدل معاينة الواجهة. أكد أن الميزانية صفر، وأنه أضاف بطاقة إلى Render ولا يملك خدمة بريد. لا تفويض بخدمات مدفوعة أو تجاوزات استخدام مدفوعة.

## الموارد الفعلية

| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Supabase Petra     | مشروع `yzvcinbdeoffygmtptxi`، مخطط التطبيق الخاص سبق تجهيزه؛ لم يُربط بخادم التطبيق                                                |
| Render Key Value   | `petra-runtime-queue`، المعرف `red-dbdchdjncjis739ngpb0`، فرانكفورت، `free`، `available`، `noeviction`، لا حفظ قرصي ولا وصول خارجي |

لوحات الإدارة: [Render](https://dashboard.render.com/)، [Supabase Petra](https://supabase.com/dashboard/project/yzvcinbdeoffygmtptxi). هذه ليست روابط للموقع.

## عوائق التشغيل الفعلي

- **التكلفة:** راجعنا [وثائق Render المجانية](https://render.com/docs/free) الحالية. وجود بطاقة يسمح بفوترة تجاوز النقل والبناء. [سقف البناء](https://render.com/docs/build-pipeline#setting-a-spend-limit) يخص دقائق البناء؛ لا دليل هنا على سقف شامل لكل الرسوم، ولا أداة متاحة لقراءة إعداداته أو تغييره. لم ننشئ Web Service قبل حسم شرط الصفر.
- **البريد:** منافذ SMTP المعتادة محجوبة مجانًا؛ الموصل الجديد يستعمل Resend HTTPS. يلزم حساب مجاني ومفتاح إرسال على الخادم. [حصص المزود](https://resend.com/docs/knowledge-base/account-quotas-and-limits) حالياً 100 رسالة/يوم و3000/شهر. المرسل التجريبي يتيح بريد صاحب الحساب فقط؛ النطاق الموثق لازم للإرسال العام. لا تعطل تأكيد البريد أو تزور حالة التحقق. لا تدخل المفتاح في Git أو المحادثة أو متغيرات المتصفح.
- **توزيع الخدمات:** عامل Render المستقل ليس نوعًا مجانيًا؛ وخدمات الويب المجانية لا تستقبل اتصال الشبكة الخاصة. حزمة Compose الحالية تفترض API وعاملاً وشبكة خاصة وبوابة WebSocket؛ لا تنشرها كما هي ولا تحوّل العامل إلى endpoint عام بديلًا.
- **Redis:** المورد المنشأ غير مربوط. اتصال Render الداخلي الافتراضي لا يطابق اشتراط التطبيق `rediss` مصادقًا. يلزم إعداد اتصال TLS فعلي والتحقق منه دون تعطيل فحص الشهادة أو فتح قاعدة المهام لكل الإنترنت.
- **الملفات:** التخزين المحلي على Render مؤقت. التطبيق يغلق الرفع خارج `local`، ويحتاج موصل تخزين خاص وفحصًا فعليًا وتعريفات حديثة ووصلة فاحص خاصة. لا يوجد مسار استضافة مجاني متحقق لهذه الحزمة بعد.
- **الأعمال الاختبارية:** `finance/ledger.ts` و`services/dispatch.ts` يقيدان عمليات sandbox بـ`local`، والهوية تفرض loopback لهذا الوضع. لا تمرر `APP_ENV=local` على موقع عام. تجربة المعاملات المستضافة تحتاج تصميم staging صريحًا وعزل وصول وبيانات وصلاحيات، لا إزالة الحارس.
- **قاعدة البيانات:** أدوار التشغيل والترحيل ما زالت بلا LOGIN. يلزم اتصال خاص عبر TLS وجلسة تدعم LISTEN، وفصل الأسرار، واختبار من الخادم الفعلي. لا يكفي نجاح استعلام من أداة Supabase.

## المتبقي قبل إعطاء رابط تجربة كاملة

1. إثبات منع الرسوم خارج الميزانية في إعدادات حساب الاستضافة، أو اختيار منصة ذات حد إنفاق صلب متحقق.
2. ربط البريد مع حساب المالك، وتجربة التسجيل والتأكيد والاستعادة برسائل تصل فعليًا. يمكن بدء حساب Resend من [صفحة التسجيل](https://resend.com/signup)، مع إبقاء تجاوزات الخطة المدفوعة معطلة.
3. اعتماد وتنفيذ مخطط استضافة staging مناسب للموارد المجانية، وفحص الذاكرة والشبكة والعامل والتخزين والفاحص، مع بقاء المال الخارجي مغلقًا.
4. نشر نسخة محددة، ثم فحص HTTPS والجلسات وCSRF وWS والكتابات والصلاحيات والملفات عبر الرابط الفعلي. نتيجة محلية أو صفحة تعرض التصميم ليست إثباتًا لهذه الخطوة.

إضافة البطاقة لم تعد العائق الوحيد. لا وعد بأن جميع وظائف البنية الحالية ستعمل مجانًا دون تعديل، ولا ترقية تلقائية أو نشر معاينة بوصفها تشغيلًا كاملاً. أدلة الجولة في `evidence/free-hosting-2026-10-23.json`، وقرار البريد ADR031.
