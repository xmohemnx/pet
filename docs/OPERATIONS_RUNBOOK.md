# تشغيل Petra المحلي وإدارة الأعطال

## بدء التطوير

من `/workspace/pet`، باستعمال Node 24 وpnpm 11.25.0 وDocker وFFmpeg/FFprobe:

```bash
bash scripts/install-cloud.sh
pnpm dev:api
# طرفية ثانية
pnpm dev:web
# طرفية ثالثة، بعد بناء API
pnpm dev:worker
```

منافذ API 4000، الويب 3000، وفحص عامل المهام 4002 على loopback. PostgreSQL وRedis وMailpit عبر Compose. API يعاد بناؤه عند البدء ولا يراقب التغييرات؛ الويب يدعم HMR. لا تبدأ خدمتين على المنفذ نفسه، ولا توقف عملية مجهولة. `.env` يولّدها env:prepare ويحافظ على السر الموجود؛ لا تطبع قيمها. APP_ORIGIN يجب أن يطابق الويب، وAPI_BASE_URL وجهة داخلية للـBFF.

## اختبار رحلة جديدة

ينشئ المستخدم حسابًا ويؤكد البريد من Mailpit. يعتمد المراجع العيادة والطبيب/السائق؛ لم يُنشأ مدير أو سائق أو تاجر افتراضي. داخل العيادة أضف فرعًا ثم خدمة أو منتجًا، وموردًا وطلب شراء واستلامًا. الحسابات الطبية تحتاج موافقة المالك، والتجارة والمحاسبة صلاحيات داخل العيادة.

المالية صراحة sandbox وAPP_ENV=local. لا بيانات بطاقة أو webhook موفر مزيف، ولا خصم أو تحويل مصرفي حقيقي. أسعار النقل (5000 IQD أساس و1000/كم مباشر، 90% للسائق) أرقام تجربة محلية وليست عرض تسعير إنتاجي. عمولة التجارة تبدأ صفرًا من إعداد السياسة؛ اختبار الأرقام يضبطها داخل قاعدة الاختبار وحدها.

## تفويض المالية المحلية

المراجع يحتاج MFA ومنحة إدارة أولًا كما في README. لتفويض مالي مستقل ينفذ operator مخول صراحة، لحسابين مختلفين:

```bash
PETRA_ALLOW_LOCAL_FINANCE_GRANT=true node scripts/grant-local-finance.mjs maker@example.test maker
PETRA_ALLOW_LOCAL_FINANCE_GRANT=true node scripts/grant-local-finance.mjs checker@example.test checker
```

الأداة ترفض الإنتاج والحساب غير الموثق أو دون TOTP ومنحة إدارة. ليست خطوة startup ولا seed. المعد لا يصرف طلبه حتى لو مُنح النطاقين. مالية العيادة تتطلب محاسبًا لإعداد القيد، وحسابًا آخر له صلاحية الاعتماد؛ لا تعديل لقيد مرحل.

## عامل المهام

الجسر يقرأ outbox ويرسل إلى Redis بصف منفصل لكل قاعدة. الرسالة قد تتكرر؛ notifications تمنع الأثر المكرر بـ(user,event)، وprocessed_at يحسم المعالجة. إعادة إدراج غير المحسوم بعد دقيقة تعالج فقد الصف/توقف المستهلك. خمس محاولات مع backoff ثم failed_at، وتظهر المهام في `/admin/operations` مع إعادة محاولة مدققة. لا تعني المعالجة إرسال بريد/SMS/push.

الفيديو يبقى pending حتى يتحقق FFprobe من مدته ويحوّله FFmpeg إلى MP4 لا يتجاوز دقيقة؛ فشل المعالجة يترك rejected ورسالة واضحة. الملفات داخل `.data/media` خاصة وليست static public. نسخ التطوير لا تنشرها على object storage أو CDN قبل ضبط التحكم بالوصول والفحص والسياسات.

انتهاء حجز checkout بعد 20 دقيقة يعيد reserved تلقائيًا. توقف العامل يؤخر الإشعارات والتحويل وتحرير الحجز، ولا يلغي معاملة زيارة/طلب نجحت. راقب health العامل وصف pending/failed واستأنفه دون تعديل سجلات أعمال يدويًا.

## النسخ والاسترجاع

```bash
pnpm backup:verify
# للاحتفاظ بنسخة اختبار الاسترجاع محليًا بدل حذفها
PETRA_KEEP_VERIFIED_BACKUP=true pnpm backup:verify
```

الأداة تعمل على قاعدة petra محلية فقط، وتُصدر snapshot متسقة، ثم تُنشئ `petra_restorecheck_<pid>` منفصلة وتسترجعها وتقارن كل جدول وتتحقق من وجود حماية القيود والتدقيق. تنسخ الوسائط الجاهزة وتتحقق من SHA-256. تحذف قاعدة التحقق فقط في finally. المجلد خاص داخل `.data/backups`، والدَمب يحتوي بيانات حساسة؛ لا ترفعه إلى Git أو evidence. اختيار الاحتفاظ صريح، والافتراضي حذف أرشيف الاختبار بعد نجاحه. ليست جدولة نسخ إنتاجية أو خطة RPO/RTO معتمدة.

## قبل أي إطلاق فعلي

تحتاج الاستضافة/النطاق/HTTPS وSMTP الإنتاجي، ومزود دفع وخرائط وتخزين وفحص وسائط واتفاقات قانونية ومحاسبية واحتفاظ، وتهيئة trusted proxy ومحدد معدل نشر حقيقي، ومراقبة وإنذارات ونسخ دوري واختبار استعادة مستقل. راجع KNOWN_ISSUES وREQUIREMENTS_TRACEABILITY؛ فحوصنا المحلية لا تحل محل تدقيق مستقل أو موافقة مالك خدمة خارجية.

## تشغيل 0.10.0 وحماية الأسرار

شغّل migrations الجديدة 0014/0015 ثم أعد API والعامل من البناء الجديد. الجلسات الإدارية السابقة للترحيل لا تعتمد؛ يلزم دخول TOTP جديد، والاعتماد المالي يتطلب جلسة خلال 30 دقيقة. API_HOST=127.0.0.1 افتراضيًا؛ فتحه يحتاج شبكة داخلية مضبوطة. حالات رفض الحجم 413 والضغط 415 ومحاولات الرفع 429 مقصودة، والمهلات لا تبرر تعطيل الحماية.

`pnpm security:check` ثم `pnpm security:built` بعد البناء. راجع [SECURITY_REVIEW](SECURITY_REVIEW.md) لحدود المتصفح وCSP والملفات وTLS والبوابة. secret:scan لا يفحص ملف env الخاص مباشرة؛ صلاحياته وموقعه ومنع إضافته وتسرب قيمه تغطيها security:check. لا ترفع traces الآلية التي قد تحمل cookies.

## تشغيل 0.11.0

طبق حتى 0019 وأعد API والعامل. worker يجدول مراحل التذكير ويفحص deferred_notifications بعد انتهاء DND؛ تعطيل القناة يلغي التسليم، ولا رسائل خارجية. راقب تراكم التأجيل وطول صف outbox. رمز QR bearer مصرح للنشر المحدود؛ لا تسجل قيمه أو روابطه كاملة. public safety لا يفتح الجواز owner-only. إزالة إجازة لا تعيد أوقاتًا ألغاها النظام؛ انشر أوقاتًا جديدة بعد معالجة التوفر. إغلاق حملة يبقي التبرعات والقيود والردود محفوظة ولا يحول أموالًا.

## تشغيل 0.12.0

طبّق 0020/0021 وأعد API والعامل من البناء الحالي. health phase=catalog-storefront-local. تضاف واجهة primary للعيادات القائمة والجديدة دون تعديل ملكيتها أو منح عضوية. إخفاء المتجر يوقف بيعاً جديداً، ولا يلغي طلباً محفوظاً أو يحذف بيانات مالية. لتعطيل صورة احذف ارتباطها واحفظ؛ تحقق من ارتباطات أخرى إن ظلت متاحة. الصور المرفوعة غير المرتبطة تبقى خاصة؛ لا تحول مجلد الوسائط إلى static. السياسات النصية لا تحسب رسوم شحن أو ضرائب. التحديث المتعارض يرجع 409؛ أعد التحميل وراجع النص الحالي قبل حفظ جديد.

## تشغيل 0.13.0

migrations حتى 0027، ثم إعادة API والعامل والويب. إذا انتهت دفعة بعد تحصيل طلب، يرفض الشحن دون خصم مخزون؛ عالج الاستبدال بمخزون صالح أو مسار تسوية معتمد، ولا تعدل تاريخ الدفعة أو تقيد رداً وهمياً. لا فاتورة PO جزئية: استلم المتبقي ثم طابق الفاتورة. السداد الجزئي يترك المستحق billed حتى تمامه، وترفض الدفعة الزائدة، ويمكن رفض موافقة معلقة وإعداد بديل. تقارير التاريخ لا تشمل drafts.

تابع إلغاء النقل المجدول الفائت عبر worker وoutbox. تغيير ملكية حيوان أو سحب وصاية booking يمنع قبول طلب نقل لم يعد صاحبه مخولاً به. التتبع يدوي وسجله immutable؛ لا تكتب رقم تتبع يوحي بشحنة من مزود غير مستخدم. دفتر العناوين خاص لكن الطلب يحتفظ بعنوانه السابق وفق متطلبات السجل. إزالة قصة مميزة لا تسحب نسخة سبق أن حفظها قارئ مصرح له.

## تشغيل 0.14.0

طبق migrations 0028–0030 دون تعديل السابق، ثم أعد API والعامل والويب. الكوبون يحسب الحجز غير المنتهي والتحصيل استخداماً؛ الإلغاء/الانتهاء يحرره، والمرتجع لا يعيده. إذا تبدلت معاينة السعر، أعد المعاينة؛ لا تعدل لقطات الطلب أو قيوداً منشورة لتجاوز الرفض. إعداد الضريبة تجريبي صفر افتراضياً، بجلسة MFA مالية، ولا يفعل أي ضريبة قانونية أو مزود دفع خارجي.

التجميل: أنشئ خدمة في الفرع وغرفة وعضواً بصلاحية service_staff أو clinic_admin، ثم وقتاً يستوعب المدة والإضافات. سجل الإشغال المشترك يمنع التعارض مع الزيارة الطبية أيضاً. الإخفاء لا يلغي حجزاً سابقاً؛ ألغِه برد اختباري قبل التنفيذ أو راجع التسوية إذا نفد المستحق. تأكيد الإتمام عمل موظف مخول وينقل المؤجل إلى إيراد مرة واحدة. صور الإتمام بموافقة مستقلة؛ يمنع نشر الملف المرتبط في المجتمع/المتجر.

المكتبة: مسودة المدير ثم مراجعة طبيب مختلف عن محرر النسخة ثم نشر صريح. كل تعديل يعيد المسودة ويخفي المنشور. تعليق العيادة أو الطبيب/انتسابه أو مرور سنة على المراجعة يحجب القراءة، ولا يمثل إكمال review اعتماداً خارجياً. طلب التصحيح والرد يحفظان النسخة القديمة؛ إصلاح المحتوى يحتاج نسخة ومراجعة ونشر جديدين. لا تنشر محتوى علاجياً اصطناعياً للمستخدمين الحقيقيين. لا تضف بيانات/كلمات مرور افتراضية للبيئة.

## تحديث باقات الرعاية 0.15.0

طبق الترحيلين 0031/0032 بعد نسختك الاحتياطية المعتادة ثم أعد API والعامل والويب بالبناء الجديد. ترحيلات 0001–0030 لا تتغير. للتحقق من تحويل البيانات القديمة بأمان استخدم `node scripts/verify-plan-migration.mjs`: ينشئ قاعدة محلية مستقلة وبيانات اصطناعية ويترك قاعدة التشغيل كما هي ثم يحذف اختباره.

الصلاحية والتعليق المستأنف تلقائياً محسوبان بوقت قاعدة البيانات ولا يتوقفان على عامل. الرصيد غير المستخدم عند الانتهاء يبقى مؤجلاً حتى اعتماد سياسة محاسبية؛ لا يرحل دخلاً تلقائياً. شروط الباقات ثابتة؛ أخف الباقة القديمة وأنشئ أخرى لتغييرها. التجديد يدوي والترقية فقط لغير المستخدم وفق ADR 014. إذا رفض الرد لكفاية المستحق، راجع التسوية والحجوزات المالية؛ لا تعدل القيد أو العداد أو تاريخ الاشتراك لتجاوز الحماية.

نقل الحيوان أو أرشفته يمنع استخدام اشتراك المشتري السابق؛ لا تحويل تلقائي للحقوق المالية. تحتاج هذه الحالات سياسة دعم وعقود إنتاج قبل تشغيل أموال حقيقية. تبقى `.env` و`.data` والنسخ خارج Git والمجلدات العامة وحزم التنزيل.

شغّل `pnpm check` ثم `pnpm test:e2e` بالتتابع. اختبار الحماية يضع canary اصطناعياً مؤقتاً في public ثم يحذفه؛ لا توازِ هذا الفحص مع خادم الاختبارات أو القياسات. يحتفظ فحص الحمل بحدوده، ولا تعني محاولة GET إضافية عند انقطاع الاتصال اعتماد أداء إنتاجي.

## تشغيل 0.16.0 — الزيارات المنزلية

طبّق 0033 بعد النسخ المعتاد وأعد API والعامل والويب. لا تعدل 0001–0032 أو تحرك عداد استخدام/قيد/حالة طلب مباشرة. يبدأ المشغل بخدمة طبية لا تحتاج غرفة، وطبيب معتمد ومنتسب، وعرض مدينة/حي وأنواع وسعر خدمة وانتقال، ثم ينشر الطبيب أو المدير أوقاتاً. لا توجد شخصيات مزودين إضافية أو منح تلقائية.

الحجز المنزلي يتم من مساره فقط، ويخلق الموعد الطبي والتحصيل المؤجل داخل المعاملة. الإرسال والوصول للطبيب المسند، ثم حضور وبدء علاج وتوقيع من مساحة الطبيب. الإلغاء العادي للمواعيد والغياب لا يتجاوزان التسوية؛ راجع مسار الرد المنزلي قبل التوثيق. عند تغير الملكية أو سحب الموافقة يوقف التنفيذ ويحجب العنوان، والمدير يستطيع معالجة رد غير المنفذ. لا تغير موافقة مالك قديم تلقائياً عند نقل الحيوان.

الانتقال محجوز زمنياً قبل الموعد وبعده، وتراعيه الإجازات والإغلاق. ليس ETA جغرافياً؛ راجع أي حاجة لطريق أو تتبع أو SLA مع مزود معتمد. الإيصال خاص وقابل للطباعة، ولا ينشئ فاتورة قانونية. يشمل اختبار الترحيل القديم 0033 مع بقاء القيود والسجلات السابقة، ويثبت الاسترجاع وجود حمايات الربط والخصوصية.
