# نطاق التحقق الحالي — 0.19.0

هذا سجل فحوص المطور المحلية، وليس تقرير اختبار اختراق مستقل أو ضمان انعدام ثغرات. الواجهات الجديدة لا تغير صلاحيات API أو IQD3 أو ثبات القيود أو sandbox الإنتاج. الصور المُنشأة وملفات المهارات لا تتضمن أسرار تشغيل أو مرفقات طبية، وملفات المهارات مستبعدة من صورة الإنتاج.

الاتصال الفوري يقيّد الأصل والبروتوكول والحجم والمعدل والعدد ويعيد فحص الجلسة والحظر والخصوصية. لا أجسام رسائل في PG LISTEN أو outbox. المرفق مربوط بمرسل ومستلم وتسليم حاليين، ولا يعاد نشره في المجتمع/الكتالوج. كل قطعة HLS تفحص ACL الأصل. الصوت يعاد ترميزه بحدود النوع والحجم والمدة مع تنظيف الملفات المؤقتة.

موصل S3 يستخدم endpoints ثابتة وتشفير AES-GCM مربوطاً بالمفتاح وتحقق ACL/policy ومنع كتابة متكررة، لا public URL. ClamAV يعمل عبر Unix socket خاص ويفشل مغلقاً عند تعطل الفاحص أو قدم التعريفات. أعطال البنية تؤجل المعالجة مع تتبع المحاولات؛ المصدر المتقاعد يحذف بمهمة محددة الهوية بعد 24 ساعة. هذه إجراءات دفاع، وليست إثبات اكتشاف كل تهديد أو بديل سياسة احتفاظ وتدوير معتمدة.

عروض الطريق محددة المالك والعمر ومدخلات العراق وحدود استدعاء ومهلة وحجم، دون URL يختاره المستخدم. الإسناد يحتاج موافقة الطرفين ويعيد فحص التوافق؛ النزاع يتطلب طرفاً أو صلاحية مستقلة، والقرار المالي بمراجعين مختلفين وMFA وقيد عكسي فريد. قواعد DB تحمي اللقطات والتاريخ والنطاق.

فحص الإنتاج يبقى blocked مع غياب المزود والسياسة والتجهيز والتقرير المستقل. لا يُفعّل الدفع أو رفع الإنتاج بتغيير التصميم. راجع ADR018–025 وKNOWN_ISSUES ونتائج الفحوص النهائية في PROGRESS.

## مراجعة مصدرية موجهة بأداة Cloudflare

طُبقت مهارة security-audit في وضع الإرشاد على مسارات الوسائط والهوية؛ ليست تدقيقاً شاملاً أو مستقلاً. لم تنفذ مراجعة المهارة شيفرة الهدف أو طلبات إلى بنية مشتركة تحت افتراض عزل غير متحقق. كشف التتبع المصدري نقص فحص منظور المستلم إلى المرسل عند قراءة مرفق محادثة؛ أضيف فحصه مع الإبقاء على سياسة خصوصية المستلم. تغطي اختبارات تطوير المشروع سحب خصوصية المرسل والمتابعة والوصول إلى الملف وقوائم HLS وقطعه، ولا تمثل تلك الاختبارات اعتماد sandbox التدقيق المستقل. راجع ADR026.

تبقى حقيقة عنوان العميل خلف proxy وحدود المعدل في طوبولوجيا الإنتاج، وإعدادات مزود التخزين وTLS وتدوير المفاتيح، بحاجة تحقق تشغيلي على البنية التي ستُختار. لا تُعامل ملاحظة تقوية أو فرضية تعتمد على نشر غير موجود كثغرة مؤكدة أو نتيجة اختبار اختراق.

# مراجعة وتقوية أمان Petra — سجل حتى 0.18.0

طلب المالك استكمال الخطة مع التركيز على منع كشف `.env`. هذه مراجعة مصدر واختبارات محلية محددة، وليست شهادة خلو من الثغرات أو اختبار اختراق مستقل. لا يوجد نشر إنتاجي عام في هذه المهمة.

## حماية الأسرار

- `.env` في جذر المستودع، خارج `apps/web/public`، وغير متعقب. نمط `.env*` مستثنى من Git إلا `.env.example` الخالي من أسرار التشغيل. صلاحية الملف الفعلي `0600`، والتهيئة تحفظ السر الموجود وترفض الرابط الرمزي.
- الويب وAPI يرفضان مسارات الملفات المخفية، ومنها `.env` وGit، وصيغ الترميز المتكرر والنسخ والمفاتيح. الاختبار يتحقق من HTTP 404 و`no-store` عبر التطبيقين؛ لا يعتمد على robots.txt لحماية الملفات.
- لا تصدير لأسرار إلى `NEXT_PUBLIC_*` أو إعداد `env` في Next. `security:built` يفحص ملفات JavaScript/CSS وبقية ملفات المتصفح العامة بحثًا عن قيم أسرار التشغيل، ويرفض source maps عامة.
- `security:check` يفحص المصدر وpublic وفهرس Git، حتى الإضافة القسرية لملف env، ويرفض الروابط الرمزية وتسرب قيم الأسرار المعروفة. secretlint يفحص أنماط الأسرار أيضًا. الاختبار يزرع سرًا اصطناعيًا في public ويتأكد من اكتشافه دون طباعته.
- أُضيف hook قبل commit وفُعّل محليًا. يتفعّل أيضًا في install-cloud. يمكن تجاوز hooks محليًا؛ لذلك تظل الفحوص في CI ضرورية. أصبحت النسخة 0.14.0 متعقبة ومرفوعة إلى GitHub؛ ما سبق عن unborn يخص نقطة الإعداد الأولى. فحص المصدر وفهرس Git لا يعادل تدقيقاً مستقلاً لكل سجل بعيد أو فحص اختراق.
- حزمة المصدر ينشئها `scripts/package-source.py` بعد فحص أصول المتصفح. تستبعد env الفعلي وGit و`.data` والنسخ والوسائط والاعتماديات والبناء وتقارير/تتبعات الاختبار. `.env.example` فقط مسموح. CI لا يرفع traces التي قد تتضمن cookies أو أجسام طلبات.

## MFA والمال والخصوصية

- ترحيل 0014 يسجل حد الجلسة عند تغير حالة MFA. الجلسة السابقة لهذا الحد لا تكفي للإدارة أو الاعتماد المالي. بعد الترحيل يلزم تسجيل دخول جديد للحسابات المعنية.
- اعتماد القيد/صرف المورد واعتماد المرتجع وصرف تسوية المنصة يحتاج MFA وجلسة عمرها 30 دقيقة كحد أقصى. تبقى صلاحيات العيادة والتفويض المالي المستقل وفصل المعد والمعتمد مطبقة؛ MFA لا يمنح صلاحية مالية بذاته.
- تغطي الاختبارات غياب MFA، والجلسة القديمة، والجلسة السابقة لتفعيل MFA، ثم الوصول إلى تحقق المورد بعد استعادة الجلسة الصحيحة. fixture أمين الصندوق يفعّل MFA عبر المكتبة الرسمية، ولا تُخفّف حماية التطبيق لتنجح الاختبارات.
- يستطيع صاحب الحساب إزالة متابع أو رفض طلبه، ويستطيع المتابع الإلغاء. المحفوظات تعيد فحص الخصوصية؛ الحفظ لا يمنح وصولًا بعد إزالة المتابع أو الحظر أو انتهاء القصة. المرفق يخضع للتحقق نفسه. قائمة الحظر تعرض أسماء وأزرارًا بدل طلب UUID يدويًا.

## معالجة الملفات

الصور PNG/JPEG/WebP فقط، بفحص محتوى فعلي وحد للبايتات والبكسلات، وإعادة ترميز وإزالة metadata ومهلة معالجة. الفيديو في حجر pending حتى فحص المدة وإعادة الترميز. FFprobe/FFmpeg يفرضان demuxer MOV/MP4 وبروتوكولات file/pipe فقط، ويمنعان external data references والمسارات المطلقة للـtracks. المخرج محدود الحجم ومحفوظ 0600، والمجلد 0700؛ يمنع وضعه تحت public أو .next أو استخدام روابط رمزية.

قراءة الملف تستخدم O_NOFOLLOW وفحص أنه ملف عادي وحد حجمه؛ اختبار رابط رمزي إلى ملف canary يرجع 404 دون قراءة السر. لا يعتبر هذا antivirus أو عزل OS لعملية FFmpeg. الإنتاج يرفض الرفع المحلي حتى إعداد مزود تخزين وفحص وعزل مناسبين.

## بوابات الإنتاج وما لم يُثبت

الإنتاج يرفض demo والمفتاح الضعيف وPostgreSQL دون `sslmode=verify-full` وRedis دون TLS/كلمة مرور، ويتطلب HTTPS وSMTP موثقًا مع TLS. الوضع local يتطلب origin على loopback. العمليات المالية الحقيقية والتخزين المحلي غير مفعلين في الإنتاج.

قبل إطلاق عام يلزم مزودو الإنتاج والسياسات القانونية والاحتفاظ، TLS/WAF وحدود اتصالات وحمل عند المدخل، حسابات DB بأقل صلاحية منفصلة عن migrator، تشفير النسخ والتخزين، تدوير الأسرار، مراقبة وتنبيه، وتدقيق مستقل. IP المستخدم للهوية مأخوذ من socket ولا يثق بـX-Forwarded-For؛ خلف BFF تشترك المحاولات في هوية loopback، وهذا حد توافر يحتاج تكامل gateway موثوقًا ومختبرًا قبل إطلاق عام، ولا يجوز حله بالثقة العمياء بترويسات الزائر. لم تُجر اختبارات DDoS أو تدقيق أنظمة المضيف أو سلسلة إمداد كاملة.

إذا تسرّب سر بالفعل، حجبه لاحقًا لا يكفي: يُدوّر من مدير الأسرار، وتُبطل الجلسات ذات الصلة وتُراجع آثار الوصول والنسخ والسجلات. لا يوجد دليل في هذه المراجعة أن سر التشغيل الحالي نُشر.

أوامر التحقق والنتائج النهائية مسجلة في [PROGRESS](../PROGRESS.md)، والبنود الوظيفية المتبقية في [KNOWN_ISSUES](../KNOWN_ISSUES.md).

- لا شراء لحيوان غير مملوك أو مؤرشف، ولا استهلاك بعد نقل الملكية. القراءة والتعليق والاستئناف والتجديد والترقية والإلغاء تعيد فحص المالك الحالي؛ الطبيب يعيد فحص الترخيص والانتساب والموعد والموافقة العلاجية.
- الاستحقاق لقطة خدمة وحصة وعيادة وفرع. لا زيارة غير موقعة أو قبل الأهلية أو أثناء التعليق، ولا إعادة احتساب زيارة على اشتراك آخر. قفل ومعاملة وقيد فريد ودفتر استخدام ثابت، مع تحقق DB مؤجل من العداد والحصص والمبلغ المعترف به.
- شروط الباقة والاشتراك والسجل محمية في DB؛ التحصيل/الترقية/التجديد داخل sandbox بمفاتيح طلب، وطلبات الواجهة تحتفظ بالمفتاح خلال فشل الطلب وإعادة المحاولة داخل الصفحة. الترقية تعكس الأصل وتثبت الجديد ذرياً وبخلف واحد، ولا تنقص الحقوق. إعادة تحميل الصفحة بعد فشل تحصيل غير محسوم تستلزم مراجعة الاشتراكات المحفوظة قبل شراء آخر.
- رد غير المستخدم خلال سبعة أيام يحتاج مستحقاً كافياً بعد الحجوزات المالية. اختبار قاعدة مؤقتة يحقن حجزاً غير متسق للتأكد من تراجع الرد كاملاً؛ لا تُخفف ضوابط طلب الصرف الفعلية لتوليد هذه الحالة.
- فحص الترحيل مستقل على بيانات اصطناعية قديمة واستخدام جزئي؛ يثبت بقاء القيود الأصلية ودقة الاستحقاق، دون تعديل migration سابقة. أُصلح عنوان API الخاص بالويب دون demo في اختبارات Playwright ليشير إلى خادم الاختبار 4101، فلا يعتمد على خادم تطوير 4000 خارج قاعدة الاختبار.

يبقى حد كل هذه الأدلة هو الحالات المحلية المنفذة. لا ضمان انعدام ثغرات، ولا تشغيل دفع خارجي أو تجديد مصرفي دوري أو اعتماد قانوني/محاسبي من هذه الإضافة.

## الزيارات المنزلية — 0.16.0

العنوان والاتصال في سجل خاص؛ لا إسقاط لهما إلى المواعيد العامة أو الكتالوج أو الأحداث أو تفاصيل التدقيق. قراءتهما للمالك الحالي أو المسند أو استقبال/مدير العيادة ضمن موافقة وملكية واعتماد حاليين؛ لا يصل المحاسب أو موظف خدمات أو طبيب آخر بتغيير ID. تسجل قراءة فريق الإرسال والإيصال بالمعرف فقط. الواجهة نصية ولا تنفذ محتوى العنوان.

السعر والمدة والانتقال من العرض الثابت، والحجز للمالك غير المؤرشف بموافقات صريحة ومفتاح طلب. لا تسمح APIs العادية بحجز الوقت المنزلي أو إلغائه أو تسجيل غيابه دون تسوية. قيود DB تربط الطلب والموعد وتمنع حذف التاريخ أو تغيير اللقطات أو إتمام غير موقع. حجز الانتقال يشارك قواعد التداخل مع الرعاية والتجميل؛ لا قفل ذاكرة متصفح. التوقيع والرد يستخدمان المعاملة والقفل المالي ومراجع ثابتة، ولا يجمعان حقوق باقة مع تحصيل المنزل.

تبقى قاعدة البيانات والمشغل الموثوقان ضمن حدود الثقة؛ لا تشفير تخزين خارجي أو سياسة محو عنوان أو تدقيق اختراق مستقل مستمد من هذه الإضافة. لا اعتماد إنتاج أو ضمان انعدام ثغرات.

## الفندق: 0.17.0

المالك الأصلي الحالي غير المؤرشف وحده يقرأ عقده؛ الوصي أو المالك الجديد لا يرث بيانات عقد المالك السابق. إدارة الإقامة لفريق عيادة مخول، ويُحجب المحاسب غير التشغيلي. المراجعة لطبيب موثق ومنتسب، ويُعاد فحصه عند الوصول. ملاحظات المراجعة والوزن واللقاح تُحجب عن الاستقبال ومدير غير طبيب؛ لا توسيع لقراءة EHR. لا نص صحي أو حادث في outbox أو التدقيق؛ القراءات تُدقق بالمعرفات.

شروط الوحدة والعقد ومراجعات القبول والحوادث لا تعدل ولا تحذف؛ الإصلاح بمراجعة جديدة قبل الوصول أو حل مستقل للحادث. قيود الوحدة والحيوان تمنع التعارض حتى مع السباق. قفل مالي ثم الحيوان ثم الحجز يوحّد ترتيب المعاملات. الرد يراعي الصرف المعلق، والمغادرة تعترف بالمؤجل مرة واحدة. healthReviewed من المتصفح لا يثبت مراجعة؛ قرار الطبيب محفوظ ويتحقق منه الخادم وقيد قاعدة البيانات. تمنع المغادرة عند بقاء عاجل بلا حل، وحل العاجل للطبيب. هذه ضوابط محلية، ولا تثبت صحة مستند لقاح أو تشكل سياسة احتفاظ قانونية أو تدقيق اختراق مستقلاً.

فحص فهرس Git يقرأ blob لكل نسخة مفهرسة عبر cat-file --batch، مع تحقق النوع والحجم وحدود المحتوى؛ أي قراءة ناقصة ترفض الفحص دون طباعة buffers أو أسرار. يغطي الاختبار سراً اصطناعياً ثنائياً موجوداً في الفهرس وحده ونسخة عمل نظيفة، بالإضافة إلى canary في public وenv مفروض في فهرس معزول. لا يتوقف الفحص عند ملفات القرص ولا يتجاهل الملفات الثنائية، وتبقى حدود الاختبارات دون زيادة.
