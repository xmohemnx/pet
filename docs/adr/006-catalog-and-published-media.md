# ADR 006 — كتالوج العيادة والصور المنشورة

الحالة: مطبق محلياً في 0.12.0، ضمن نموذج التجارة والملكية الحالي.

كل خيار منتج صف حقيقي في products له SKU وسعر وحجز وطبقات FIFO مستقلة. parent_product_id يجمع الخيارات لمستوى واحد مع مفتاح مركب clinic_id وقيد يمنع الأصل الذاتي وtrigger يمنع التعشيش. لا تعديل لعائلة SKU بعد الإنشاء في API الحالي، ولا تفكيك تلقائي لسطور طلبات سابقة. تعطيل الأصل يخفي عائلته من الاكتشاف والطلبات الجديدة. تعطيل خيار منفرد يخفيه وحده. لا مصفوفة توليد مقاسات وألوان آلية بعد.

التصنيف والعلامة والعمر والوحدة والباركود والمواصفات نصوص محدودة؛ عرضها عبر React بلا HTML خام. حتى ست صور مرتبة مع وصف بديل. التحديث بversion ومراجعة clinic_admin أو commerce_manager في عيادة موثقة؛ يبقى inventory_clerk لاستلام المخزون دون تعديل الكتالوج. سعر الطلب من قاعدة البيانات، وتبقى كلفته ومورّدوه وحركاته خارج DTO المشتري.

واجهات clinic_storefronts المتعددة القائمة محفوظة. يوجد primary واحد بفهرس جزئي لكل عيادة، ينشأ تلقائياً ويُعاد ملء العيادات الموجودة؛ واجهة هذا الإصدار تدير primary فقط. الاسم والسياسات والمدينة والتوفر والشعار والغلاف بنطاق العيادة، لا شخصية تاجر مستقلة. التوفر والسياسات نصوص إرشادية، لا مزود شحن أو احتساب رسم أو تنظيم قانوني تلقائي. الإخفاء يمنع الطلبات الجديدة ويحجب واجهة المتجر وصوره؛ الطلبات السابقة قابلة للعرض والمعالجة وفق حالاتها.

الرفع يظل خاصاً حتى ربط الصورة وحفظها بموافقة نشر صريحة. يقبل الخادم صورة ready يملكها الفاعل وpet_id فارغاً، ويرفض الصور الطبية والفيديو والوسائط غير الجاهزة. يجوز لزميل مخول الاحتفاظ بصورة مرتبطة مسبقاً بالمورد نفسه عند تعديله، ولا يمنح ذلك حق إعادة استخدام ملف خاص لموظف آخر. قيود DB تتحقق من نوع ومصدر الصورة الطبي أيضاً؛ الصور نفسها لا تنتقل إلى public.

قراءة الوسيط من غير صاحبه تتطلب ارتباطاً منشوراً حالياً بمنتج نشط وعائلة متاحة ومتجر منشور وعيادة موثقة، أو ارتباط منشور آخر جائز كمنشور اجتماعي ظاهر. إزالة ارتباط الصورة أو إخفاء المتجر/المنتج يسحب إذن ذلك الارتباط فوراً؛ لا يمحو نسخة سبق أن حفظها المشتري. فحص السرية الطبي يبقى سابقاً لهذه القواعد. مسار الملفات يتطلب جلسة موثقة، وإعدادات no-store وO_NOFOLLOW والحدود السابقة باقية.

التغطية: catalog.spec يختبر cross clinic، FK/trigger العائلة، رفض السرقة/المرفق الطبي/غياب الموافقة، سحب النشر، version، DTO بلا تكاليف، رصيد وسعر كل خيار، تكرار checkout وتزوير السعر، إخفاء المتجر وتعليق العيادة، ثم رفع وحفظ فعلي من المتصفح ورحلة SKU وسلة على 390px مع axe وصور أدلة. القوائم حتى 200، ولا مزود صور إنتاجي أو CDN/SEO عام أو ضرائب وخصومات جديدة في هذا القرار.
