# 021 — إسناد عروض النقل بموافقة الطرفين

خيار الإسناد الآلي غير مفعل افتراضياً للعميل أو للسائق. يرشح العامل مركبة معتمدة وسارية ومتاحة في المدينة نفسها، تستوعب كل الحيوانات وأنواعها والراكب المصاحب، دون رحلة نشطة أو عرض آخر. الاختيار عادل وفق أقدم عرض سابق، ولا يدّعي اختيار الأقرب جغرافياً؛ لا نجمع موقع السائق أثناء انتظاره.

العرض خاص لسائق واحد لمدة 45 ثانية، ويحتاج قبوله الصريح. انتهاء العرض أو رفضه يسمح بعرضه لسائق مؤهل آخر، وحتى عشرة مرشحين مختلفين. يبقى الطلب ظاهراً للاختيار اليدوي عندما لا يوجد عرض حصري صالح. الإسناد غير متاح خارج sandbox ما دام التحصيل الحقيقي غير مهيأ.

قفل dispatcher في قاعدة البيانات ينسق عدة عمال مع قبول الرحلة وتعديل المركبة والإلغاء. فهارس فريدة تمنع عرضين معلقين للرحلة أو للسائق، وتمنع رحلتين نشطتين للسائق نفسه. الترحيل يرفض وجود رحلات نشطة متعارضة قديمة؛ لا يلغي بيانات حالية تلقائياً. سجل العروض ثابت الهوية ولا ينتقل إلا من pending إلى حالة نهائية. إشعار outbox يحتوي معرف العرض فقط؛ لا نقطة انطلاق أو وجهة قبل القبول.

المهلة وسياسة الإلغاء والتعويض الحالية تشغيلية اختبارية وليست شروط خدمة عراقية معتمدة. تتطلب سياسة الإطلاق موافقة قانونية وتشغيلية منفصلة.
