# 024 — فيديو VOD متكيف خاص

يُولد العامل مشتقات HLS مسجلة بجودتين (حتى 240p و360p) إلى جانب MP4 الحالي. FFmpeg يعمل بخيط واحد وصيغة مصدر محصورة وبروتوكولات file/pipe، وحد 30 ثانية لكل جودة، ومقاطع أربع ثوان وحد أقصى 16MiB للمشتقات. لا نسخ متعددة لا محدودة ولا رابط مزود يدخل subprocess. يبقى الأصل غير منشور حتى نجاح المعالجة.

قائمة master وقوائم الجودة ومقاطع MPEG-TS لها معرفات مستقلة ثابتة في `media_streams`؛ مسارات القوائم يولدها الخادم نحو API فقط ولا تحتوي عنواناً خارجياً أو مفتاحاً أو مسار قرص. يعاد تحقق صلاحيات الأصل عند **كل** طلب قائمة أو مقطع، بما فيها خصوصية المنشور والمحادثة والحظر وانتهاء story. النسخ والاسترجاع يشملان كل ملف مشتق جاهز. ليس هناك public bucket أو مفتاح URL دائم.

المشغل يستعمل HLS الأصلي حيث يدعم، وhls.js محملاً عند اختيار المستخدم للتشغيل المتكيف، ويبقي خيار MP4. التكيف يبدل الجودة وفق الاتصال؛ لا يغير صلاحيات الملف. هذا بث مسجل VOD، وليس استضافة بث حي أو غرف WebRTC. تفعيل التخزين والفحص والإنتاج والسعة يحتاج تحققاً منفصلاً؛ ترميز الفيديو أو اختبارات المشغل لا تشكل مراجعة أمنية مستقلة.
