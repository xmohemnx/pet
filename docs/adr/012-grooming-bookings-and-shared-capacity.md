# 012 — التجميل وسعة مشتركة مع المواعيد

التجميل خدمة عيادة وفرع، بموظف ذي صلاحية service_staff أو مدير، وغرفة من موارد الفرع. إضافات السعر والمدة معرفّة على الخادم، والقبول حسب نوع الحيوان. كل موعد يلتقط الاسم والسعر والإضافات والمدة ورضا الصور؛ لا قراءة للسجل الطبي ضمن التجميل.

سجل clinic_booking_occupancy بقواعد PostgreSQL exclusion يجمع إشغال الحيوان والموظف والغرفة من المواعيد الطبية وحجوزات التجميل. يتحدث بtriggers في المعاملة نفسها، فيمنع التداخل عبر المجالين حتى لو اختلف مسار API أو تزامنت الطلبات. يحتفظ بالصف بعد الإلغاء/الإتمام مع active=false. الأوقات UTC والعرض بغداد؛ لا حجز مفتوح بلا حدود أو جداول افتراضية.

التحصيل محلي اختباري عند الحجز مع إيراد مؤجل، والاعتراف عند إتمام موظف مخول فقط. الإلغاء قبل التنفيذ يعكس التحصيل والمؤجل مرة واحدة ويعيد السعة، ويرفض الرد إذا استنفد المستحق. السعر والهوية والمدة غير قابلة للتعديل؛ لكل تغيير audit وoutbox. صور الإتمام أربع صور جاهزة فقط بموافقة صريحة قابلة للسحب، وصلاحية للعميل صاحب الحجز مع وصاية حالية أو الفريق المخول، ولا نشر تلقائي للمجتمع.

هذه شريحة التجميل على الويب؛ ليست زيارات منزلية، أو إثبات فحص صحي/لقاح، أو تعاقد دفع إنتاجياً. لا تقدم مستنداً ضريبياً قانونياً؛ الإيصال تشغيلي اختباري قابل للطباعة.
