# ADR 018 — الاتصال الفوري وحدود إطلاق Petra

طلب المالك تنفيذ بنود التكسي والطبيب والتجارة والإدارة والسوشل وتجهيز النشر للعراق باسم Petra، باستعمال أدوات مجانية قابلة للتوسع. لا يملك حالياً نطاقاً أو استضافة أو حسابات مزودين. اختيار البرمجيات المفتوحة لا يوفر هوية تجارية أو بوابة دفع أو جهة إصدار تراخيص أو اعتماد فاتورة أو مراجعة أمنية مستقلة تلقائياً.

## الاتصال الفوري

WebSocket من مكتبة ws، بنفس جلسة الهوية وOrigin المسموح، دون tokens في URL. الكتابة المالية والرسائل الدائمة تبقى عبر HTTP بمفتاح طلب؛ الاتصال ينقل إشعارات تغيير بالمعرفات فقط، ويقرأ العميل الرسائل من DB بعد التحقق من الصلاحيات. PostgreSQL NOTIFY داخل المعاملة يتيح الإشعار بعد commit وعبر نسخ API متعددة، والرسائل الدائمة تعاد قراءتها عند الاتصال والتعافي.

الاشتراك في محادثة يعيد استخدام سياسة الحظر والخصوصية نفسها. تعاد مصادقة الجلسة والصلاحية عند الأفعال والنبض والإشعارات، مع حدود payload واتصالات ومحاولات ومعدل وإبطال عند الانقطاع. الحضور ومؤشر الكتابة اختياريان بموافقة صريحة، مع TTL في Redis دون كشف آخر ظهور. Redis ينظم اتصالات المستخدم عبر النسخ؛ تعطل البنية يغلق الاتصال ولا يجيز مساراً بلا صلاحية. يبقى HTTP fallback عند تعذر WS.

إنتاجياً يمر WSS عبر النطاق نفسه في reverse proxy؛ التطوير loopback فقط. CSP يسمح بالعنوان المحدد فقط، لا اتصالات عامة. لا ضغط WebSocket أو رسائل ثنائية أو تحميل ملفات أو إرسال نصوص خاصة عبر قناة pub/sub، ولا logging للكوكيز أو bodies.

## حدود الاعتماد

تُسجل حالة كل بند ونتائج اختباره والعائق الخارجي في PRODUCTION_PLAN. لا تحويل التحصيل الاختباري إلى دفع حقيقي بمجرد تغيير APP_ENV، ولا وسم مراجعة يدوية على أنها تحقق خارجي، ولا مستند بعنوان «معتمد» دون جهة إصدار. النسخة المعدة للنشر لا تُوصف بالجاهزة للعامة قبل فحوصها والمعلومات والعقود المطلوبة.
