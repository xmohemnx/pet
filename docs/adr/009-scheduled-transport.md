# ADR 009 — النقل المجدول ومتعدد الحيوانات

حتى خمسة حيوانات للحجز الواحد، مع فحص صلاحية booking لكل حيوان عند الطلب ومجدداً عند قبول السائق. لا أسماء أو عناوين أو إحداثيات للطلبات العامة قبل الإسناد. المركبة تقيد العدد والأنواع والراكب المصاحب، والقبول يعيد التحقق داخل قفل المركبة والرحلة؛ يبقى قيد رحلة نشطة واحدة للسائق.

الموعد الاختياري UTC من خمس دقائق حتى 30 يوماً، يعرض بتوقيت بغداد. يظهر الطلب للسائق ويقبل خلال نصف ساعة قبل الموعد إلى ساعتين بعده. الطلب المجدول غير المقبول بعد المهلة يلغيه العامل بأثر واحد؛ لا مبالغ مسبقة أو جزاءات إلغاء جديدة. الموقع لا يشارك قبل القبول أو بعد الإلغاء/الإكمال.

الملاحظات نص محدود خاص بالراكب والسائق المسند. سعر المسافة المستقيمة الاختباري الحالي محفوظ للحجز الواحد ولا يعد تسعير طريق أو تأميناً أو مزود نقل إنتاجي؛ لم يضف التنفيذ رسوم مزود أو جزاءات مالية غير معتمدة. لا مطابقة آلية أو تتبع خلفي، والقبول اختيار واعٍ من سائق مؤهل ضمن مدينته.
