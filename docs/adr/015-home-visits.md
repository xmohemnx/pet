# 015 — الزيارات المنزلية المرتبطة بالرعاية الطبية

الزيارة المنزلية عرض لعيادة وفرع وخدمة وطبيب موثق ومنتسب، بنوع حيوان ومنطقة مدينة/حي وسعر خدمة وانتقال ومدة انتقال قبل الموعد وبعده. المنطقة وصف يقره العميل، وليست نتيجة تحقق خرائط أو احتساب طريق. الشروط ثابتة؛ إتاحة العرض بإصدار، وتغيير الشروط بعرض جديد. ينشر الطبيب أو مدير العيادة أوقاتاً حتى ثلاثين يوماً.

يُنشأ موعد طبي من نوع home وطلب منزلي في معاملة واحدة. الأوقات المنزلية لا تقبل الحجز عبر مسار العيادة العادي ولا تظهر في قائمته. `occupied_from` يحجز انتقال الطبيب قبل الموعد، و`occupied_until` بعده مع فاصل الخدمة. قيود الطبيب والحيوان والغرفة وسجل الإشغال المشترك تشمل كامل الفترة؛ إغلاق العيادة أو إجازة الطبيب يفحصانها أيضاً. لا شخصية مزود مستقلة ولا إسناد لطبيب غير معروف.

الحجز للمالك الحالي لحيوان غير مؤرشف، بسعر خادم ومفتاح طلب وموافقة صريحة على عنوان خاص وعلى مشاركة الملف الطبي مع الطبيب المحدد حتى يوم بعد نهاية الموعد. لا تُدمج الموافقتان في قبول عام. الموافقة القائمة الأطول لا تقصر تلقائياً. تُعاد صلاحية الطبيب والانتساب والملكية والموافقة عند الإرسال والوصول والعلاج. نقل الملكية أو سحب الموافقة يحجب العنوان عن فريق التنفيذ ويوقف العمل؛ يبقى للمدير مسار إلغاء ورد قبل بدء التوثيق.

العنوان والاتصال والملاحظات في جدول خاص، خارج قوائم المواعيد العامة والملف الطبي وoutbox والتدقيق. يقرأها المالك الحالي أو الطبيب المسند أو موظف استقبال/مدير العيادة المخول، وبموافقة وملكية واعتماد حاليين. لا يرى المحاسب أو موظف التجميل أو طبيب آخر العنوان. لا تنتقل بيانات العنوان السابق إلى المالك الجديد.

الحالات confirmed ثم en_route قبل الموعد بساعتين كحد أقصى، ثم arrived قرب الموعد، ثم حضور وبدء علاج الطبيب في مسار المواعيد، ثم توقيع الزيارة الذي يتمم الطلب ويعترف بالإيراد مرة واحدة. لا يكفي زر إتمام مستقل. تحفظ قاعدة البيانات تطابق حالة الموعد والطلب وعدم حذف التاريخ، وتمنع الغياب أو الإلغاء العادي من تجاوز التسوية المالية.

التحصيل الاختباري عند الحجز مؤجل، والرد الكامل قبل العلاج/توثيق الزيارة؛ العميل يلغي قبل الموعد والمدير يعالج الحالة بعده ما دامت لم تبدأ. الرد يفحص المستحق بعد الحجوزات المالية، ولا ينشئ ذمة سالبة خفية. التوقيع يرحل المؤجل إلى إيراد داخل المعاملة نفسها. لا تجمع حقوق باقة مع زيارة منزلية مدفوعة حالياً. الإيصال المطبوع تشغيلي اختباري وليس فاتورة ضريبية قانونية. لا تفعيل PSP أو تحقق ترخيص خارجي أو خدمات خرائط أو تتبع حي ضمن هذه الإضافة.
