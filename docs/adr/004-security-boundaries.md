# ADR 004 — أسرار الخادم وحدود الطلب وMFA المالي

الحالة: مطبق محليًا في 0.10.0.

كان BFF يقرأ الجسم كاملًا دون حد، وكان محلل رفع API يسبق التحقق من الجلسة، وكانت سياسة CSP تفتقر إلى قيد السكربتات. إعفاء `.env` من Git وحده لا يغطي ملفات public أو حزم المتصفح أو الأرشيف.

نعتمد فحص أسرار للمصدر والفهرس وpublic والبناء والحزمة، وحدود stream وOrigin قبل القراءة، وقبول رفع موثق ومحاولات مدفوعة حتى عند فشل الملف، وnonce لكل استجابة HTML. API داخلي افتراضيًا، والملفات الخاصة خارج static وبـO_NOFOLLOW. الاعتماد المالي يحتاج MFA وجلسة حديثة وحدًا بعد التفعيل، فوق صلاحية المورد وفصل الأشخاص.

يتطلب nonce عرض HTML عند الطلب بدل توليد الصفحات العامة ثابتًا. يسمح CSP بـinline styles الحالية، ولا يوسع ذلك إلى inline scripts. حدود الرفع داخل العملية مكملة لحد PostgreSQL، ولا تحل محل بوابة اتصالات موزعة أو عزل معالجة الوسائط. إعداد production يرفض التكوينات غير الآمنة المدعومة بالفحوص، لكنه لا يثبت سلامة البنية الخارجية أو خلو التطبيق من الثغرات.

التفاصيل والاختبارات والحدود في [مراجعة الأمان](../SECURITY_REVIEW.md).
