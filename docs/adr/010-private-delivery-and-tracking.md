# ADR 010 — عناوين التسليم وتتبع الطلب

دفتر عناوين خاص بالحساب، حتى عشرين عنواناً، مع version والتعديل والحذف. إنشاء الطلب يأخذ عنواناً محفوظاً يملكه صاحب الجلسة أو نصاً مباشراً للتوافق، ويخزن snapshot مستقلة؛ تعديل العنوان أو حذفه لاحقاً لا يغيّر طلباً محفوظاً. تعيد إعادة المحاولة بالمفتاح نفسه الطلب نفسه، حتى لو تغير دفتر العناوين، بشرط تطابق مدخلات الطلب الأصلية. لا تكاليف شحن أو مزود أو تحديد موقع ضمن دفتر العناوين.

العنوان الكامل ورقم التسليم يظهران للمشتري وفريق تجارة العيادة صاحبة الجزء اللازم من الطلب. لا صفحة عامة ولا عرض لعيادة أخرى أو ملف مجتمع. التتبع يدوي من الفريق المخول: ناقل ورمز نصي مع version، وأحداث تجهيز/شحن/تسليم من آلة حالات الطلب نفسها وسجل immutable. رمز التتبع لا يتحول إلى URL خارجي؛ لا جلب روابط أو SSRF ولا ادعاء webhook لمزود فعلي.
