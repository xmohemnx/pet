# 013 — مكتبة رعاية بمراجعة مستقلة

المقالات نصوص تعليمية مرتبطة بعيادة، دون HTML تنفيذي أو جلب روابط من الخادم. يديرها مدير العيادة، ويحفظ كل تعديل revision ثابتاً مع اسم محرره ونوع الحيوان والفئة العمرية ومراجع HTTPS. كل تعديل يلغي النشر والمراجعة الحالية. طبيب موثق ومنتسب للعيادة، مختلف عن محرر النسخة، يوافق أو يرفض مع ملاحظة محفوظة؛ بعدها فقط ينشر المدير النسخة المراجعة. سحب اعتماد العيادة أو الطبيب يخفي المحتوى من العميل فوراً.

تاريخ المراجعة واسم الطبيب ظاهر في المقال؛ بعد سنة تُحجب النسخة المنشورة حتى تحرير نسخة جديدة ومراجعتها. هذه مهلة تشغيلية قابلة للتطوير، وليست اعتماداً للمعلومة أو تشخيصاً فردياً. لا مقالات بيطرية مولدة ومنشورة تلقائياً ولا ادعاء اعتماد خارجي.

للقارئ إرسال تصحيح خاص بمعدل وحد يومي وحد معلق واحد لكل مقال. يحفظ الطلب revision الذي رآه، ويرد المدير بملاحظة؛ حل البلاغ لا يعدل المقال أو يعيد نشره ولا يمحو الأصل. القارئ يرى طلباته وردودها، وموظفو المحتوى يرون طلبات عيادتهم فقط، دون بريد القارئ أو سجله الطبي. audit وoutbox لكل كتابة.
