# ADR 003 — استكمال الموقع والدفتر ومعاملات الاختبار

الحالة: قيد التنفيذ، 2026-10-21. طلب المالك الاستمرار دون توقف بين المراحل.

- الإبقاء على Next/Nest وPostgreSQL والعقود الصارمة وخمس شخصيات؛ وحدات domain مستقلة داخل نفس النواة بدل توزيع خدمات مبكر.
- تنفيذ الدفتر قبل ربط أي تدفق تجاري. integer bigint في قاعدة البيانات وBigInt في الحسابات، وعرض المال كسلاسل عبر JSON. كل دفتر منفصل وIQD، قيود متوازنة بمفاتيح مصدر فريدة، وفترات مقفلة، وأصل مرحل غير قابل للتعديل وعكس مستقل. تطبق قاعدة البيانات التوازن والاحتفاظ أيضًا.
- المنتجات والمخزون والمشتريات مملوكة للعيادة. checkout يحسب السعر من الخادم ويقسم حسب العيادة ويقفل المنتجات بترتيب IDs؛ الحجز منفصل عن الشحن والتسليم والمرتجع.
- الاختبار المالي صريح: mode=sandbox، مسارات تحصيل تحت /sandbox وبوابتها APP_ENV=local. لا webhook مزيف يدعى أنه موفر دفع، ولا تحويل بنكي حقيقي أو تحصيل تبرعات إنتاجي. نسب sandbox يحددها إعداد السياسة، والافتراضي صفر عمولة لا سياسة تجارية ضمنية.
- maker/checker لعمليات الصرف والقيود اليدوية: إنشاء واعتماد من حسابين مخولين مختلفين. الإدارة العامة لا تعطي صلاحية مالية ضمنية.
- الطلب/المخزون/الدفتر/الأحداث ضمن معاملة واحدة عند انتقال الحدث المستحق. outbox بمستهلك محدود retries وdead letters وإشعارات داخل التطبيق؛ تسليم القنوات الخارجية يحتاج adapter معتمدًا.
- اشتراكات الرعاية لها حقوق استخدام ودفتر usage ذري؛ الفندق وحدة مؤرخة مع منع تداخل على PostgreSQL. المنصة الاجتماعية تطبق الخصوصية والحظر قبل القراءة والكتابة وليس بالواجهة.
- تخزين الملفات محلي خاص في التطوير، مع حدود وفحص magic bytes وحجر للوسائط التي تحتاج معالجة. لا نشر ملف فيديو قبل فحص وتحويل فعلي، ولا URL عام لملف طبي.
- الموقع لا يَعِد بإرسال فريق إنقاذ أو سيارة قبل قبول جهة مخولة. الموقع الدقيق للبلاغ والرحلة للمشاركين المصرح لهم فقط، ويختفي بتوقف المشاركة/انتهاء الرحلة.
- اختبارات القبول تمر على PostgreSQL مؤقتة وواجهات API حقيقية. لا تعادل اختباراتنا مراجعة أمنية أو محاسبية مستقلة أو موافقة قانونية أو نشر متاجر التطبيقات.

## حدود التشغيل المتحققة

المخزون FIFO بطبقات واستعادة تكلفة جزئية، والتحصيل مؤجل إلى التسليم. الاشتراك يعترف بالقيمة عند استعمال حق لزيارة موقعة، ويعالج باقي القسمة في الاستعمال الأخير. الأموال المقيدة ليست إيراد المنصة. الصرف المتاح للعيادة يستبعد إيرادها المؤجل والطلبات المحجوزة للصرف؛ يُعاد فحصه عند التنفيذ. لا يعالج الرد بعد نفاد مستحق العيادة بإنشاء ذمة سالبة خفية: يرفضه للمراجعة دون رد مالي.

القفل المالي الشامل الحالي يبسّط التسلسل في هذه النسخة المحلية؛ ليس تصميمًا مثبتًا لحمل مالي واسع. قوالب الدفاتر محددة، لا ضرائب أو دفعات جزئية أو تعويض طبيب تلقائي دون عقود. السجلات الأصلية محمية، والتحقق لا يساوي اعتماد السياسات المحاسبية محليًا.

الوسائط صور WebP مع إزالة metadata وفيديو MP4 مُحوّل محليًا عبر FFmpeg. ليست فحص برمجيات خبيثة معتمدًا أو CDN/HLS متعدد الجودة. PostgreSQL وملفات الوسائط الجاهزة خضعتا لنسخ واسترجاع إلى قاعدة/مجلد مستقلين مع مقارنة المحتوى ووجود triggers؛ لم يثبت استرجاع snapshot السحابة في مهمة جديدة.
