# ADR 030 — معاينة واجهة مجانية على Render

الحالة: اختار المالك بتاريخ 2026-10-23 معاينة مجانية محدودة للواجهة داخل مساحة Render المسماة `My Workspace`.

## القرار

ننشر خدمة ويب واحدة من صورة Next standalone الحالية على خطة `free` المقبولة في أداة Render، دون API أو عامل أو Redis أو بيانات اتصال Supabase. هذا الاختيار يخص المعاينة فقط؛ لا يغير بنية التشغيل الكامل أو شروط هوية الإنتاج، ولا يفعّل معاملات أو بيانات تجريبية.

يقتصر المتاح في `PETRA_WEB_PREVIEW=true` على الصفحة العامة وتصميم نماذج الهوية وصفحة تشرح حدود المعاينة والأصول المطلوبة. تظهر لافتة عربية واضحة، وتعطل حقول وأزرار نماذج الدخول والتسجيل والاستعادة. يرفض الخادم جميع مسارات API بـ503 دون اتصال خلفي، ويمنع طلبات الكتابة، ويخفي demo وروابط الأمان، ويوجه بقية الصفحات إلى صفحة الحدود. يمنع فهرسة المعاينة، ولا يجلب sitemap بيانات من API. وضع المعاينة لا يتلقى أسرار قاعدة أو جلسات أو مفاتيح خدمات.

يُستخدم إنشاء Render المباشر بدلاً من Blueprint لأن النطاق المختار أصبح خدمة ويب واحدة بلا خدمات مرتبطة. يحتفظ النشر باسم الفرع والـcommit الفعليين ولا يدمج مسودة PR إلى main. لا تعني الخدمة الحية اكتمال التشغيل؛ تظل قاعدة Supabase الخاصة جاهزة ومنفصلة حتى إعداد خادم كامل ومزوديه.

## التحقق والحدود

نختبر بناء Next الفعلي مع وضع المعاينة، واستجابة الصفحة والأصول، ورفض القراءة والكتابة للـAPI، وغياب أي طلب إلى خادم خلفي مراقب، وتعطيل النماذج على الهاتف مع axe. بعد إنشاء الخدمة نراقب deploy حتى `live` ونتحقق من رابطها الفعلي قبل إعلان النجاح. إذا تعذر طلب الموقع من بيئة العمل بسبب سياسة الشبكة فلا ننسب إليه تحقق HTTP لم يُنفّذ.

أدوات Render متصلة، لكن جلب وثائق الأسعار الحالية بصيغتَي Markdown وHTML رُفض بـ403 من سياسة شبكة بيئة العمل. نستخدم قيمة `free` الصريحة في مخطط الأداة ولا نعد بتوفر دائم أو حدود تشغيل غير متحققة. لا ننشئ خدمة مدفوعة أو قاعدة إضافية.
