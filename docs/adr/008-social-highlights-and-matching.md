# ADR 008 — البحث والقصص المميزة ومقترحات المفقود

القصص العادية تنتهي بعد 24 ساعة. اختيار صاحبها قصة مميزة بموافقة صريحة يبقي رابط المصدر نفسه قابلاً للعرض حتى سنة، وفق خصوصية المنشور والملف والمتابعة والحظر الحالية. إزالة المميزة بعد انتهاء القصة تسحب الوصول للمنشور والوسيط، ما لم يوجد ارتباط مشروع آخر. لا نسخة عامة ولا تجاوز لخصوصية صاحب الملف. feed القصص يستبعد المنتهي حتى لو كان مميزاً؛ القائمة المميزة مستقلة. أرشيف آخر 100 قصة خاص بصاحبها. لا حذف سجلات طبية أو مالية ضمن هذه العملية.

المشاهدة فعل صريح idempotent لقصة ظاهرة، وقائمة المشاهدين لصاحبها فقط وبأسماء الملف الاجتماعي دون بريد أو اتصال، وتعيد تصفية الحظر. البحث في نص المنشورات يعيد استخدام visibleSql ويحمل الاستعلام كمعامل SQL، والمشاركة رابط داخلي يراجع الصلاحية مجدداً عند الفتح، دون نسخ محتوى خاص أو إرسال خارجي تلقائي. المحادثة المفتوحة تتحدث كل أربع ثوانٍ عند ظهور الصفحة مع إلغاء الطلب عند إغلاقها؛ ليست WebSocket أو وعد تسليم لحظي. أي رفض في القراءة يوقف التحديث ويغلق المحادثة.

مقترحات lost/found لصاحب بلاغه فقط: نوع مقابل في المدينة نفسها، ملاءمة نوع الحيوان، حالة منشورة بعد المراجعة، خلال 90 يوماً، حتى 20 اقتراحاً. تعرض حقول البلاغ العامة دون عنوان خاص أو هوية اتصال، ولا تدعي إثبات ملكية أو تطابق هوية الحيوان. قرار التسليم ومحادثته المدارَة وتحقق الجهة تبقى إجراءات مستقلة.
