# ADR 019 — تصنيفات العيادة والوسوم والبحث

شجرة مستقلة لكل عيادة حتى أربعة مستويات، وأسماء ومسارات ثابتة مع إتاحة بإصدار. إنشاء بتسلسل ومفتاح طلب، دون نقل تصنيف بين العيادات أو إنشاء دورة. إخفاء تصنيف يخفي فرعه من فلاتر التصنيفات ولا يلغي نشر المنتجات أو الطلبات؛ إخفاء المنتج نفسه يظل من إدارته.

ربط المنتج بتصنيف واحد وعشر وسوم كحد أقصى بإصدار المنتج، دون تغيير التصنيف النصي القديم أو SKU أو السعر أو المخزون أو الصور. قيود DB تطابق العيادة وتمنع الأسماء والوسوم غير المطَبّعة أو المكررة. لا اختيار جديد لتصنيف مخفي أو ذي أصل مخفي.

البحث المصنف في الخادم يعيد فقط SKUs والمتاجر المنشورة والعيادات المعتمدة، مع بحث نصي ووسم وفرع شجرة. الفلاتر العامة لا تكشف تصنيفات مسودات بلا منتج منشور. واجهة البحث تحتفظ بالمنتجات المختارة في السلة عند تغيير النتائج، وتظل معاينة السعر والطلب من الخادم. الحد الحالي 200 نتيجة و500 تصنيف لكل عيادة؛ SEO والفوترة والمزودات منفصلة.
