# 025 — تخزين S3 خاص مشفر وفحص ClamAV

اختار المالك أدوات مجانية دون حسابات مزودين. الموصل يستعمل AWS SDK المعياري مع endpoint قابل للتبديل لخدمة S3 ذاتية الاستضافة؛ SeaweedFS بديل Apache-2.0 بعد تعذر سحب صورة MinIO العامة. لا يعني ذلك نجاح تشغيل الإنتاج أو وجود استضافة مدفوعة أو مجانية لدى المالك.

ملفات S3 تشفر في التطبيق بـAES-256-GCM ومفتاح مستقل 32 بايت في secret خاص؛ AAD يربط المحتوى بمفتاح التخزين. لا يكفي تسريب رابط object لفك محتواه. يمنع الموصل bucket ACL أو سياسة تسمح بقراءة عامة، ويحتاج HTTPS خارج loopback المحلي. لا ترسل مفاتيح S3 أو التشفير للمتصفح. القراءة تمر عبر صلاحيات الأصل عند كل طلب كما في ADR 023/024. نسخ قاعدة البيانات وحدها لا تسترجع الوسائط؛ نسخ bucket المشفر ومفتاح التشفير خارج النسخة العامة يحتاج اختبار استرجاع مستقل.

فحص ClamAV عبر Unix socket خاص مشترك بين خدمات API والعامل والفاحص، دون منفذ TCP عام. يقيد حجم INSTREAM والوقت والاستجابة، ويرفض تعريفات أقدم من سبعة أيام. إيقاف الفاحص أو تعذر فهم الرد يفشل مغلقاً؛ لا تتحول الملفات إلى ready باعتبار الفحص ناجحاً. EICAR عينة اختبار معيارية، وليست برمجية خبيثة فعلية. التعريفات والفاحص يحتاجان تحديثاً دورياً وصوراً مراجعة مثبّتة ببصمة.

التفعيل الحالي للاختبار المحلي المعزول. يبقى رفع الإنتاج مغلقاً إلى حين إغلاق بوابات الاحتفاظ والخصوصية والمراجعة المستقلة وإجراء اختبار نشر على البنية الفعلية. إعادة الترميز أو نجاح EICAR لا يثبتان استحالة الثغرات. المرفقات الطبية الرسمية والتحقق من الترخيص والتوقيع القانوني تحتاج سياستها وجهة اعتمادها، ولا تستنتج من وجود object storage.

يحتفظ العامل بالرفع في الحجر ويعيد فحص المصدر والناتج قبل نقل الحالة إلى ready وتثبيت المشتقات معاً. انقطاع التخزين أو الفاحص يؤجل المعالجة دقيقة بدلاً من إسقاط الملف أو اعتباره آمناً. تُجدول المصادر الخام المتقاعدة بعد التحويل للحذف بعد 24 ساعة عبر media_gc_jobs، مع إعادة المحاولة بعد عشر دقائق؛ لا تحذف المهمة مشتقاً جاهزاً. هذا تنظيف تقني محدود، وليس دورة احتفاظ أو طلبات حقوق كاملة.

أداة النسخ المحلية تشمل pending وprocessing وready والمشتقات. تحتفظ بنسخة الأجسام البعيدة مشفرة، ويتحقق الاسترجاع في قاعدة منفصلة. اختبار المزودين يستخدم SeaweedFS وClamAV فعليين مثبتين ببصمة، مع اعتماديات وأسرار اصطناعية في .data/provider-check خارج المصدر؛ نتائجه المحلية تسجل في PROGRESS ولا تعني اختبار مزود إنتاج أو إدارة مفاتيح خارج الخادم.
