# ADR 007 — الدفعات والاستلام الجزئي وتسويات المخزون

الحالة: تنفيذ محلي فوق نموذج SKU والدفتر الحالي، دون تغيير حدود الدفع الإنتاجي.

المستودع تابع لعيادة وقد يرتبط بفرع، ولكل عيادة مستودع رئيسي تلقائي. طبقة FIFO تحمل مستودعاً ورمز دفعة وتاريخ صلاحية وحالة حجر. السعر والكلفة والمخزون من الخادم. AVAILABLE مجموع المتبقي من الطبقات غير المحجورة وغير المنتهية ناقص الحجوزات، بحد أدنى صفر؛ لا بيع للمنتهي. تاريخ الصلاحية شامل لنهاية يوم بغداد. الشحن يعيد فحص الطبقات بعد قفل المنتج؛ انتهاء دفعة بعد تحصيل طلب يوقف الشحن للمراجعة ولا يدعي رداً مالياً تلقائياً.

النقل بين المستودعات يحفظ الكلفة وتاريخ FIFO والدفعة والصلاحية والحجر ولا يغيّر الرصيد المالي الإجمالي. الحجر يمنع إتاحة بضاعة، ويرفض حجز وحدات سبق تخصيص مجموعها للطلبات. لا توزيع للحجوزات على مستودع محدد في هذا الإصدار. المرتجع الصالح يحفظ صلاحية ومصدر طبقته ولا يصبح مخزوناً غير مؤرخ تلقائياً.

استلام جزئي موثق بـGRN مستقل وidempotency ومجموع مستلم لا يتجاوز PO، وقيد مخزون/استلام غير مفوتر بالكمية الفعلية فقط. مسار الاستلام الكامل السابق يستلم المتبقي، ثم مطابقة الفاتورة تتطلب استلام كل PO. لا فاتورة جزئية ضمن هذا القرار. الإتلاف طلب من مخوّل مخزون واعتماد مالي حديث من شخص آخر ذي صلاحية صرف، مع قيد مصروف/مخزون وحركة immutable وoutbox؛ لا تعديل رصيد من المتصفح.

كل كتابة مالية تحت ترتيب القفل المالي الحالي ثم المنتج/الطبقة؛ إنشاء الطلب يقفل المنتجات بترتيب ثابت ويقرأ الإتاحة بعبارة SQL جديدة بعد القفل، لتجنب الاعتماد على snapshot قبل انتظار القفل. الضوابط السابقة للأسرار والرفع وMFA وعيادة المورد باقية. هذا لا يعتمد سياسة ضرائب أو مزوداً أو شهادة أمن إنتاج.
