# 034 — داشبوردات الحسابات ومحتوى الدخول والملفات المهنية

2026-10-23. طلب المالك خمسة داشبوردات، أيقونات وتصميماً حديثاً، بنرات يتحكم بها مدير المنصة، أقسام متجر قابلة للإدارة ومخازن داخل العيادة، وتوثيق حسابات وملفات للطبيب والعيادة بإحصاءات العمل والنتائج والأعمال الخيرية.

نوسع وحدات Nest الحالية ولا نغيّر المعمارية أو الشخصيات الخمس. ملخصات الداشبورد مشتقة من بيانات الخادم ومقيّدة بالنوع والعضوية؛ إدارة المنصة تجمع أدواتها، مع بقاء التحقق بخطوتين وفصل الاعتمادات المالية وخصوصية الطب. لا يُمنح دور مدير عند التسجيل.

البنرات لها مسودة/نشر وجدولة وترتيب ونسخة، وصورة اختياريّة مرفوعة من المدير دون نطاق طبي أو محادثة. لا روابط خارجية أو HTML أو سكربتات. الصورة متاحة للمستخدمين المسجلين أثناء نشر البنر فقط، وتبقى قواعد الوسائط الأخرى نافذة.

توثيق هوية الحساب منفصل عن اعتماد المهنة؛ الطلب يُراجع إدارياً بسبب موثق ومنع المراجعة الذاتية، ويمكن سحب التوثيق دون حذف سجل التدقيق. اختيار نوع الحساب أو طلب توثيق الهوية لا يمنح ترخيصاً طبياً.

الملف المهني يعرض بيانات منشورة وإجماليات فقط. لا أسماء حيوانات أو أصحابها أو ملاحظات طبية. سجل إجراء واحد لكل زيارة مكتملة وموقعة؛ النوع جراحة/علاج والنتيجة معلقة/ناجحة/غير ناجحة والعمل الخيري مستقل. الادعاءات لا تدخل الملف العام إلا بعد مراجعة مدير مستقل؛ لا يعد إكمال الزيارة نجاحاً علاجياً ولا تصنع نسبة نجاح من غياب النتيجة. القيم العامة إحصاءات منصة موثقة وليست ضماناً طبياً.

إدارة الأقسام تدعم التسمية والترتيب والإخفاء والحذف المنطقي للقسم الفارغ؛ يمنع حذف قسم له منتجات أو فروع حتى نقلها. تبقى المعرّفات والعلاقات ومفاتيح التكرار محفوظة، ولا يمس ذلك المخزون أو القيود. المستودعات والدفعات والنقل والاستلام تبقى داخل clinic_id.

حدود الوسائط مضافة إلى حراس0046، دون استبدال حراسة ألبومات المجتمع والصور الشخصية. قفل أصل الوسيط مشترك بين إدراج البنر وصور إتمام العناية لمنع إعادة تصنيف أصل عام كسجل خاص. عامل الوسائط غير المتزامن يختار الصوت والفيديو فقط؛ الصور يفكها مسار الرفع المتزامن، فلا تمر صورة معلقة إلى محول الفيديو.
