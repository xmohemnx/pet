# نوع الحساب الثابت وإغلاق الحساب — 2026-10-23

توجيه المالك: التسجيل يعرض عميل/طبيب/عيادة/سائق تكسي الحيوانات، وكل نوع له قسمه، ولا يتغير دون طلب للإدارة. مدير المنصة لا يظهر ضمن التسجيل الذاتي. القرار [033](../adr/033-fixed-account-types.md).

## السلوك المنفذ

| المسار                          | السلوك                                                                                                                                  |

نوع الحساب مستقل عن الصلاحيات المهنية: اختيار «طبيب» لا يمنح زيارة مريض، واختيار «عيادة» لا ينشئ عيادة معتمدة. يستطيع الطبيب الانتماء لعدة عيادات للعمل الطبي، ولا يكتسب صلاحيات محاسب/سائق بتبديل قائمة. يمكن لحساب العيادة التنقل بين عياداته المخولة. الإدارة الداخلية تبقى مساراً منفصلاً ممنوحاً إدارياً.

## البيانات والحماية

الهجرة `0047_fixed_account_types.sql` تضيف `auth_users.account_type/closed_at` وجدولي الطلبات والإغلاق وحارسين. في الحسابات السابقة يختار الترحيل العضوية التشغيلية للعيادة أولاً، ثم الطبيب، ثم السائق، وإلا العميل، ويوقف الاعتمادات المخالفة مع حفظ التاريخ وسجل قرار الترحيل. لا تُحذف حسابات أو دفاتر بسبب الترحيل.

تغيير النوع محمي في API وحارس SQL. الموافقة تلغي الجلسات والاعتمادات والعضويات السابقة؛ يلزم اعتماد مهني مستقل للنوع الجديد. الطلب وحده لا يغير شيئاً. دعوات الفريق وتعديل الصلاحيات يتحققان من نوع المستلم. يمنع تغيير النوع/الإغلاق عند بقاء مدير عيادة وحيد أو وجود رحلة نشطة أو مواعيد طبيب مؤكدة مستقبلية؛ يلزم نقل المسؤولية أولاً.

الحذف يؤكد كلمة المرور ودخولاً خلال 15 دقيقة، ويحد المحاولات. يغلق الحساب، ويلغي جلساته وبيانات اعتماده للدخول، ويموّه الاسم والبريد ويخفي ملفه ومنشوراته ويموّه معرفه الاجتماعي. حارس إدخال الجلسات يمنع إعادة جلسة لحساب مغلق. تُحفظ السجلات الطبية والمالية والتدقيق اللازمة بصورة مقيدة، وقد تبقى الرسائل لدى أطراف المحادثة؛ ليست ميزة محو شامل أو سياسة احتفاظ قانونية معتمدة. حساب إدارة المنصة يحتاج نقل المسؤولية عبر الإدارة.
