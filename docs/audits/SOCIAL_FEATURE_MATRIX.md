## ملاحظات الأمن

هذه مراجعة مصدر موجهة للتنفيذ، وليست شهادة penetration test أو تدقيقاً مستقلاً شاملاً. `visibleSql` وحظر الطرفين و`conversationAccess` و`media.authorize` هي حدود قائمة، يجب أن تغطي كل endpoint جديد. الاستنتاجات المرتبطة بالتشغيل الخارجي تحتاج تحققاً مستقلاً؛ لا تُمنح شدة لفرضية غير مثبتة. تشغيل الاختبارات الوظيفية المصرّح به يتم بقاعدة محلية معزولة وحسابات اختبار، وليس على حسابات المستخدمين أو خدمات الإنتاج.

## تحديث الشريحة الجديدة

تحديثات0045/0046 والصفحات الجديدة لا تغيّر تصنيف البداية التاريخي أعلاه. الشريحة المحددة (صورة/ألبوم → موجز → تفاعل → تفاصيل وتعليق → ملف) اجتازت10اختبارات محلية قبل0046؛ أُعيد تحقق القيود الجديدة ضمن الدورة الشاملة، وتفاصيل219سيناريو ونتائج الصور في RELEASE_EVIDENCE. يحظر قيد قاعدة البيانات إدخال مرفق طبي أوchat أوصورةتجميل خاصة في social_post_media أوavatar، حتى عبر كتابة مباشرة، ويمنع الاتجاه العكسي لتصنيف صورة منشورة كصورة خدمة خاصة. لا يصبح قسم Reels/Stories/Inbox كاملاً لمجرد وجود routes الجديدة؛ بنود المرحلة3/4 المتبقية مذكورة صراحة.
