## إعادة التشغيل والقبول اليدوي

ابدأ بمتطلبات التشغيل وملف البيئة الخاص في [README](../../README.md). يلزم PostgreSQL وRedis محليان، وFFmpeg، وChromium لتكرار قبول الفيديو والصور. لا تحفظ أسرار البيئة في Git.

1. `pnpm install --frozen-lockfile` ثم `pnpm build`.
2. `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium pnpm test:e2e social-rebuild.spec.ts --workers=1` ينشئ قاعدة اختبار محلية مؤقتة ويحذفها. غيّر مسار Chromium حسب الجهاز، أو استخدم المتصفح المثبت عبر Playwright.
3. `pnpm test:social-proof` من commit مثبت دون تعديلات على ملفات التشغيل/الاختبارات يولّد صوراً جديدة وmanifest بنفس معرف المصدر. البيانات موجودة خلال الاختبار فقط، فلا تستخدم روابط UUID المحلية بعد حذف القاعدة.
4. للتصفح المعتاد استخدم أوامر تطوير الويب/API/العامل في README، وسجّل حساباً عبر الواجهة مع البريد المحلي. افتح `/social`، أنشئ صورة/ألبوماً من `/social/create`، أعد فتح الموجز، جرّب الإعجاب/الحفظ والتعليق، ثم غيّر الملف في `/social/u/{handle}`. أدوات الخصوصية والحظر والإدارة السابقة على `/social/settings`؛ لا تعتمد على صور الاختبار لإثبات إعداد حسابك الشخصي.

عند تطبيق الهجرتين خارج الاختبار يلزم نسخ احتياطي وخطة نشر API والويب والعامل معاً. لم يُنفذ ذلك على Supabase أو أي خدمة عامة في هذه الدفعة.
