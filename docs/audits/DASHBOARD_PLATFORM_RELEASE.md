# الداشبوردات والبنرات والتوثيق والملفات المهنية

طلب المالك: أيقونات وأزرار حديثة، داشبورد لكل من العميل والسائق والطبيب والعيادة والمدير، أقسام متجر قابلة للإدارة ومخازن للعيادة، بنرات دخول يتحكم بها المدير فقط، وتوثيق الحسابات وملفات إنجازات مهنية.

## الشريحة المنفذة

- `/app` يحتفظ بدخول العميل حسب نوعه الثابت؛ البنرات المنشورة ضمن جدولها تسبق الرعاية. لا إعلان افتراضي ولا إحصاءات مختلقة.
- `/doctor`، `/driver`، `/clinic/:id` مؤشرات فعلية ومهام حسب الدور. تبقى خطوة رحلة السائق الجارية قبل العروض في DOM وداخل أول شاشة الهاتف.
- `/admin` لوحة إدارة موحدة للقرارات المهنية، الحسابات، البنرات، التوثيق، النتائج، التشغيل، المالية والنقل. لا تنشئ تسجيلاً ذاتياً لمدير، ولا تتجاوز MFA أو الفصل المالي أو سرية الطب والمحادثات.
- `/admin/professionals` يحتفظ بمراجعة الاعتماد السابقة؛ `/admin/control` إدارة البنرات والصور والجدولة والترتيب والمراجعات.
- `/clinic/:id/store` يجمع الأقسام والمنتجات والطلبات والمخازن. إعادة استخدام المخزون والدفعات والاستلام والنقل الموجودة؛ لا دفتر موازياً.
- إضافة وتعديل اسم وترتيب وإخفاء الأقسام، وحذف منطقي للقسم الفارغ بإصدار. يمنع حذف قسم له منتجات أو أبناء، ويحفظ التاريخ والمخزون.
- أقسام المتجر العامة وواجهة متجر العيادة تصل إلى منتجات منشورة، وتعرض حالة توفرها. لا دخول لبيانات إدارة عيادة أخرى.
- `/account/verification` طلب مستقل لتوثيق الهوية. المراجعة والتوثيق والسحب بإصدار وسجل تدقيق، ومنع مراجعة الشخص لنفسه. توثيق الهوية لا يمنح اعتماداً مهنياً.
- `/doctor/portfolio` تقديم نتيجة إجراء/عملية مرتبطة بزيارة مكتملة وموقعة، مع مرجع إثبات خاص وموافقة نشر. `/professional-profiles/doctor/:id` و`/professional-profiles/clinic/:id` يعرضان الأعداد والأعمال المعتمدة فقط، ويفصلان الزيارات المكتملة والنتائج قيد المتابعة. لا ادعاء أن الإحصاءات تشمل كامل تاريخ المهني أو تضمن العلاج.
- تنشر البنرات صوراً جاهزة يملكها المحرر، دون نطاق حيوان أو محادثة أو صور إتمام عناية خاصة. حراسة قاعدة البيانات وقفل الأصل يمنعان استعمال صورة عامة كسجل عناية خاص لاحقاً أيضاً.

## الحدود

تغيير مصدر وترحيل `0048`؛ لا نشر عام أو تطبيق على قاعدة الإنتاج في هذه الدفعة. الدفع والتبرعات والخدمات الخارجية تظل وفق بوابات المزود السابقة. الأدلة المرئية من متصفح فعلي وبيانات اختبار محلية، وليست بيانات عملاء أو نجاحات طبية فعلية. «لكود كلاس» افترضت Liquid Glass خفيفاً بانتظار توضيح المالك؛ الزجاج محصور بأدوات التحكم مع بديل معتم.

## التحقق

قيد التنفيذ؛ تُكتب النتائج النهائية بعد اختبارات المتصفح والمراجعة المستقلة والتوثيق.
