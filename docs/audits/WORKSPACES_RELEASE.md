## قرارات التصميم

عقد Operate [المثبت](../../apps/web/.impeccable/surfaces/professional-workspaces.md). حافظ التنفيذ على هوية Petra والخطوط المحلية والشريط الجانبي؛ تغيرت بنية العمل، لا الألوان وحدها. حالات الفراغ مفيدة دون بيانات عمل مختلقة. حجب فشل التقويم كحالة فراغ ممنوع: تعرض الواجهة رسالة تعذر التحميل ورابط الاستعادة. أرقام الفريق غير المحمّلة لا تُعرض كصفر.

استُخدمت مهارة Impeccable المحلية وإرشادات Web Interface Guidelines الحديثة. اطلع التنفيذ على مبادئ شاشات العمل المحلية أيضًا؛ لم يُسحب اتجاه بصري جديد ولم تُنتج صور تصميمية أو خرائط وهمية. الصور دليل من متصفح حقيقي على بيانات اصطناعية محلية موسومة للاختبار.

المراجعة الأولى للصور أدت إلى وضع نموذج نشر أوقات الطبيب داخل disclosure، وتمييز الإجراء الأساسي عن مشاركة الموقع والإلغاء والأفعال الثانوية. الفاحص الآلي نُفذ مرة واحدة بصياغة الملفات الصحيحة: **صفر ملاحظات أساسية و16 استشارية**، موثقة في [النتيجة](WORKSPACES_MECHANICAL_FINDINGS.json). رفضت محاولة استخدام `--target` الصياغة قبل أي فحص. الإشارات الاستشارية تخص قيمًا محلية للخطوط والزوايا ودرجات لون؛ لم يُعاد كتابة النظام العام لإخفائها.

## التحقق

- `pnpm check`: نجحت48اختبار وحدة وlint وTypeScript وPrettier وفحص الأسرار والملفات.
- `pnpm build`: نجح بناء Next وNest.
- اختبار المساحات الأول: نجح اختبار عملي واحد يغطي حالات فارغة ومملوءة، وحفظ فرع ومركبة وحجز موعد وقبول رحلة وتغيير حالتها، مع axe وفحص عرض320/390/768/1440.
- فحص TypeScript التطويري الأول فشل بسبب `toSorted` خارج مكتبة ECMAScript المحددة للمشروع؛ استُخدم نسخ المصفوفة ثم `sort` قبل البناء والتحققات الناجحة. لا تغيير لإعدادات TypeScript لإخفاء الخطأ.

الدورة الموسعة الأولى: **56passed،2failed،1skipped،10did-not-run (3.9m)**. إخفاقا الاختبار كانا في المحددات: بحث المتجر العام طابق بحث التنقل أيضًا، و`getByLabel` الدقيق لقائمة العيادة احتاج المحدد الدلالي `getByRole('combobox', {name:'العيادة'})`. ظل حقلا الواجهة وتسمياتهما صحيحين؛ صُحح الاختباران دون إضعاف التحقق. التخطي المقصود لتصوير الدفعة السابقة؛ عشرة اختبارات منصة لم تعمل بعد توقف مجموعتها المتسلسلة. أُعيد ملفا المنصة والمساحات كاملين بعد التصحيح؛ لا تُعلن الدورة الأولى خضراء ولا تجمع الإعادات كاختبارات مميزة.
