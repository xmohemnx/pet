# Petra — موقع الرعاية والخدمات

أحدث تحسينات تجربة الاستخدام موثقة في [تقرير UI/UX](docs/audits/UI_UX_RELEASE.md)، مع [صور الهاتف والحاسوب](docs/evidence/ui-ux/41851243/README.md). التغييرات على فرع مراجعة مستقل ولم تُنشر للعامة.

أحدث نسخة من مشروع Petra: Next.js للواجهة، NestJS للخادم، PostgreSQL للبيانات وRedis للمهام، بواجهة عربية RTL وخمس مساحات عمل: العميل، الطبيب، عضو العيادة، السائق، وإدارة المنصة.

يشمل المستودع الشفرة الكاملة، الاعتماديات المثبتة في lockfile، ترحيلات قاعدة البيانات الـ47، الاختبارات، الأصول المحلية، وصور Docker للويب وAPI والعامل. لا يحتوي أسرار التشغيل أو بيانات المستخدمين أو نسخة قاعدة جاهزة بحساب مدير افتراضي.

دفعة السوشل 2026-10-23 تضيف موجز الصور والألبومات والنشر والملف والتفاعل، مع إثبات أولي للقصص والريلز وDirect. هي POC عامل للمراجعة، وليست اكتمالاً للمنصة. راجع [التدقيق والاختبارات والقيود](docs/audits/RELEASE_EVIDENCE.md) و[الصور الجديدة والبدائل الثلاثة](docs/evidence/social-rebuild/f4429f36/README.md).

التسجيل يعرض أربعة أنواع ثابتة: عميل، طبيب، عيادة، وسائق تكسي الحيوانات. التغيير بطلب وموافقة الإدارة، وإغلاق الحساب من إعدادات الأمان. راجع [السلوك والتحقق](docs/audits/ACCOUNT_TYPES_RELEASE.md).

## التنزيل وتجهيز الخادم

ابدأ من [دليل الرفع والنشر](DEPLOY.md). يحتاج المشروع خادم Linux يدعم Docker Compose وعمليات مستمرة؛ رفع الملفات إلى استضافة PHP أو مجلد `public_html` وحده لا يشغله.

ملفات التشغيل:

- [Dockerfile](infra/production/Dockerfile): صور منفصلة للويب وAPI والعامل.
- [Compose](infra/production/compose.yml) و[Caddy](infra/production/Caddyfile): تشغيل الخدمات وبوابة HTTPS وWebSocket.
- [إعدادات المشغل](docs/examples/deployment.env.example) و[إعدادات التطبيق](docs/examples/production-runtime.env.example): أسماء المتغيرات فقط؛ القيم الخاصة تُضبط خارج Git.
- [قاعدة Supabase](docs/SUPABASE_DEPLOYMENT.md)، [تفاصيل النشر](docs/PRODUCTION_DEPLOYMENT.md)، و[التشغيل والمراقبة](docs/OPERATIONS_RUNBOOK.md).

**حالة النشر:** ملفات التجهيز موجودة، لكن الموقع لم يُنشر بعد. البريد واتصالات الخادم والتخزين والفحص تحتاج إعداداً واختباراً فعليين. العمليات المالية الحالية اختبارية ومحلية؛ الدفع الخارجي ورفع الملفات في الإنتاج لا يفتحان بمجرد تشغيل Docker. راجع [الحدود الحالية](KNOWN_ISSUES.md) و[حالة الاستضافة المجانية](docs/FREE_HOSTING_STATUS.md).

## التشغيل المحلي الكامل

المتطلبات: Node من السلسلة 24 بإصدار 24.5 أو أحدث، pnpm 11.25.0، Docker Compose، وFFmpeg/FFprobe. من جذر المستودع:

```bash
bash scripts/install-cloud.sh
```

يثبت الاعتماديات من lockfile ويجهز `.env` خاصاً، ويشغل PostgreSQL وRedis وMailpit، ويطبق الترحيلات والبيانات التجريبية الموسومة ويفحص المشروع ويبنيه. لا ينشئ حسابات دخول أو يمنح صلاحيات إدارية. ثم شغّل كل أمر في طرفية:

```bash
pnpm dev:api
pnpm dev:web
pnpm dev:worker
```

الويب: `http://127.0.0.1:3000`، وAPI: المنفذ 4000، وفحص العامل: 4002، وصندوق البريد المحلي: `http://127.0.0.1:8025`. أنشئ حسابك من `/register` وأكد البريد من Mailpit. منح الإدارة إجراء محلي صريح بعد التحقق من البريد وتفعيل TOTP؛ تعليماته في [دليل التشغيل](docs/OPERATIONS_RUNBOOK.md).

## التحقق وحزمة المصدر

```bash
pnpm check
pnpm build
pnpm security:built
pnpm test:db
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium pnpm test:e2e --workers=1
pnpm containers:build
pnpm test:containers
```

اختبارات E2E تنشئ قاعدة محلية معزولة وتحذفها بعد التشغيل. لفحص الخدمات الخاصة الفعلية استخدم `pnpm test:providers` وفق [دليل الوسائط](docs/MEDIA_MAINTENANCE.md). الاختبارات المحلية لا تثبت تشغيل موقع مستضاف.

لإنشاء حزمة من الملفات المتعقبة للنسخة الملتزم بها فقط، بعد نجاح البناء وفحص الأسرار:

```bash
pnpm release:source
```

الحزمة تستبعد Git وسجل تعديلاته وملفات البيئة والاعتماديات ومخرجات البناء وبيانات التشغيل، ولها ملف SHA-256 مستقل. حالة التحقق والتقدم في [PROGRESS](PROGRESS.md)، ومتطلبات المشروع في [التتبع](REQUIREMENTS_TRACEABILITY.md).

## مهارات التطوير

المهارات الـ21 محفوظة كاملةً في `.agents/skills`. لتجهيز أدواتها وفحصها:

```bash
pnpm skills:setup
pnpm skills:check
```

التفاصيل وأوامر Impeccable وVercel في [دليل المهارات](docs/SKILLS_SETUP.md). لا يملك المالك حساب Vercel حاليًا؛ تثبيت الأداة لا ينشئ حسابًا أو ينشر المشروع. أُلغي اعتماد Bolt بناءً على توجيه المالك.
